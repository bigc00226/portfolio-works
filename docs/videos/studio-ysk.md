# STUDIO 制作プロセス デモ — ワイエス建装

> 一覧ページ（`/`）と再生ページ（`/watch/studio-ysk`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/studio-ysk/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME・通知）で、長さは 5 分 24 秒 です。

画面録画用のデモページです。STUDIO のエディタを模した画面上でマウスカーソルが自動で動き、
「ワイエス建装」のコーポレートサイト（https://ysk-co-jp.studio.site/）を、ページ構成づくりから
ヘッダー・メインビジュアル・会社紹介・事業内容と施工写真・CMS のお知らせ・会社情報・お問い合わせフォームと導線まで組み立て、
タブレット / スマホの表示確認 → 公開 → 公開サイトの閲覧までを順番に再生します。

## 録画の手順

1. `public/videos/studio-ysk/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/studio-ysk/index.html でも可）
   - フォントの読み込みにインターネット接続が必要です
   - 開いた直後の数秒で、再生中に使う文字のフォントをすべて先読みします（途中でフォントが切り替わるのを防ぐため）
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始（右下のキー操作ヒントは再生開始と同時に消えます）
5. 公開サイトがトップに戻って止まったら録画を停止

再生時間は標準速度で 5 分 24 秒です（字幕・入力・ミスの場面を含む）。

| 4 | 会社紹介（ご挨拶：見出し・本文・写真）と横長の写真 | |

### 日本語入力の再現

文字入力は、実際の Windows（Microsoft IME）での操作と同じ流れで再生されます（吉武工務店の動画と同じ仕組み）。

- ローマ字を 1 キーずつ入力 → かなに変わっていく入力中の文字（点線の下線）と予測候補のウィンドウ
- Space で変換、2 回目の Space で変換候補の一覧 → Enter で確定。Tab で予測候補を選ぶ場面もあります
- 英数字（YSK、CONSTRUCTION …、ページの URL）は「半角/全角」キーで直接入力に切り替えて入力
- 一度直した変換は IME が覚えて、次からは正しく変換されます（STEP 7 の会社概要「ワイエス建装」）。
  また、STEP 2 で入力した「今日も、この街とともに」は、STEP 4 の見出しで予測候補に出てきます

## 本物と再現の区別

本物（公開中のサイトから取り込んだもの。2026-11-19 取得）：

- キャンバスに組み上がるページと公開サイト画面：公開中の https://ysk-co-jp.studio.site/ をブラウザで描画した DOM
  （STUDIO が出力した HTML 構造・クラス・`data-s-*` 属性）と、STUDIO が生成した CSS をそのまま使っています。
  全シーンの実行後、キャンバスの DOM が取り込んだページと 1 文字単位で一致することを確認しています。
- 画像：サイトの画像（STUDIO のアセット）、お知らせ記事のサムネイル（STUDIO の CMS のアセット）、
  ご挨拶の写真（サイトが STUDIO の Unsplash 連携で使っている写真）を `assets/img/` に保存して表示しています。
- サイトの文章・会社概要の内容（代表者名・所在地・電話番号など）は公開中のサイトに掲載されているとおりです（一部はサイト上でも仮の表記です）。
- フォント（Noto Sans JP・GFS Didot・Rubik など）は本番と同じく Google Fonts から読み込みます。
- 右パネルの数値（サイズ・余白・フォント・行間など）は、STUDIO が出力した CSS ルールから読み取った実際の設定値です。
  ブレイクポイントもこのサイトの CSS どおり（タブレット 〜840px / モバイル 〜540px）で、タブレット・モバイル表示の崩れの修正後の見た目は本番の CSS そのものです。
- ページ一覧（`works`・`privacy-policy`・CMS の記事ページ `GvtQcmfy/:slug`）と、ナビ・「view more」のリンク先は公開サイトのものです。
- エディタ左上のロゴ（/S）とタブのファビコンは本物の STUDIO のもの。公開サイトのタブのファビコンは、このサイトが使っている STUDIO の標準ファビコンです。
  公開サイト画面左下の「Created in STUDIO」バッジも本番サイトに表示されているものです。

再現（演出）：

- STUDIO のエディタの画面（ツールバー、左右のパネル、リンク先の選択、ページの追加、公開ダイアログなど）は、作業の流れを伝えるための簡易的な再現です
  （エディタはログインが必要なため取り込めません）。
- 要素が空の状態から追加され、文字が入力され、画像が差し込まれる順序や速さ、3 つのミスとその修正は演出です。
  スマホの表示崩れは、本番の CSS の「縦並び」をいったん外した状態を見せ、設定し直すと本番どおりになります。
- アドレスバーのプロジェクト ID はぼかしています（公開されている CMS 画像の URL に含まれる ID です）。

## 画面の環境

- Windows 11 のデスクトップで、STUDIO のエディタは最大化した Chrome のタブ（`app.studio.design`）で開いています。
  公開後の「サイトを開く」は同じウィンドウの新しいタブ（`ysk-co-jp.studio.site`）になります
- タスクバーの時計は 2026/11/14 14:00 から、動画の経過時間に合わせて進みます（お知らせの最新 2023.12.23 と矛盾しない日付）。
  サイトの取り込みは 2026/11/19 ですが、画面に出る内容に 11/14 より後の日付はありません

## サイトを更新した場合

```
npm run snapshot -- studio-ysk
```

`js/site-snapshot.js` と `assets/img/` が更新され、画像は WebP に変換されます。自動で反映されるもの・手作業が必要なものは
吉武工務店の動画と同じです（`js/editor.js` の `ASSETS` / `COLORS` / `FONT_VARS` / `FONT_LIST` / `pageHtml()`、
`js/scenario.js` の `resolve()` と `JA`、`index.html` のページ一覧）。入力ミスの台本は `JA.sideL`、リンク先の一覧は `LINKS` です。
