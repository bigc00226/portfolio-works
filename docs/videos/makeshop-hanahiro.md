# 制作プロセス デモ — 花・フラワーギフト Hanahiro ONLINE SHOP（www.hanahiro-onlineshop.jp）makeshop EC サイトの新規構築

> 一覧ページ（`/`）と再生ページ（`/watch/makeshop-hanahiro`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/makeshop-hanahiro/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME）で、長さは 5 分 7 秒です。画面の日付は 2026/11/07（土）13:10〜（途中で 13:24・13:46・14:12・14:52・15:05 へカット）。

画面録画用のデモページです。Windows 11 のデスクトップを模した画面上でマウスカーソルが自動で動き、
花・フラワーギフト Hanahiro の EC サイト（https://www.hanahiro-onlineshop.jp/）を **makeshop で構築する工程** を順番に再生します。

**カテゴリ設定 → 商品登録 → トップページ構築 → 会員登録・ログイン → 決済・配送設定 → 注文フローの確認 → 公開 → 公開ショップの確認**

## 最初に確認していただきたいこと

- www.hanahiro-onlineshop.jp は **makeshop で運営されている実在のショップ** です（画像・CSS は gigaplus.makeshop.jp / makeshop-multi-images.akamaized.net の `hanahiro8787`）。
  このデモは、そのショップを makeshop で構築する工程の **再現** で、実際の作業の録画ではありません。
- **ショップの実データ**：カテゴリー（シーン別 7・スタイル別 7）とその URL（`/view/category/mothorchid` など）、商品名・税込価格・商品画像（一覧の 48 商品）、
  ミディ胡蝶蘭 ホワイトの商品番号（6WO01）・説明文・購入オプション（ご用途・お届け希望日・同梱ギフト）、
  ご利用ガイドの決済方法（クレジットカード・Amazon Pay・PayPay）・お届け（生花はご注文の 4 日以降、17 時以降は翌日受付）・送料（東京都下 770 円／関東 1,100 円／本州・四国 1,320 円／北海道・九州・沖縄・離島 1,815 円）、
  商品ページの獲得ポイント（¥19,800 で 990 ポイント＝5%）、トップページの BY SCENE / STYLE ブロックの HTML（クラス名・リンク・画像）は、公開中のショップから取得したものです。
  ブラウザに表示されるショップの画面（トップ・胡蝶蘭の一覧・商品ページ、PC 幅 1920px / スマートフォン幅 390px）も公開中のショップを取り込んだものです。
- **makeshop の画面**：ログイン画面（https://console.makeshop.jp/login）は本物をそのまま取り込んだものです。ログイン後の管理画面はアカウントが必要なため再現ですが、
  ロゴ・アイコン・色・ページのタイトルの形式（「〇〇 - makeshop byGMO」）は管理画面自身の公開 JavaScript から取った本物です（下の「makeshop の画面について」）。
- **再現用に作ったもの**：管理画面の各ページ（カテゴリー設定・商品登録・商品一括登録・商品一覧・クリエイターモード・会員設定・決済設定・配送設定・注文一覧 / 詳細・ショップ公開設定）のレイアウトと中身、
  在庫数、CSV の列構成と商品画像のファイル名の紐付け、会員の登録項目、配送設定の画面（地域グループ・最短お届け日・送料シミュレーション）、テスト注文（T-0001）とその金額の表示、
  ショップの公開状態（非公開 → 公開）。クリエイターモードのテンプレートのソースは非公開のため、トップページの HTML はショップが配信しているマークアップそのもの（BY SCENE / STYLE のブロック）を使っています。
- 実在のショップのため、カート・ご注文手続き・会員登録・ログインは **一切操作していません**（取り込んだのは公開ページの表示だけです）。動画の「カートに入れる」はクリックの演出で、テスト注文の結果は管理画面の再現です。
- 2026/11/13 付けのショップのお知らせ（動画の日付より後）は、取り込むときにトップページとお知らせ一覧から外しています（`js/config.js` の `snapshot.remove`）。
  それ以外の内容（ウインターギフト・クリスマス・2027 年のカレンダーなど）は取り込んだときのままで、商品ページの「販売開始：2026年11月01日」などもそのままです。
- Hanahiro は実在の企業のショップです。このデモはローカルのファイルとしてだけ使ってください（Web に公開しないでください）。

## 録画の手順

1. `public/videos/makeshop-hanahiro/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/makeshop-hanahiro/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（ショップの画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「makeshop での EC サイト構築が完了」と出たら録画を停止

## 再生される内容

| STEP | 内容 | ミスと修正 |
| --- | --- | --- |
| 1 | makeshop にログイン → カテゴリー設定（シーン別「胡蝶蘭」mothorchid・スタイル別「花束・ブーケ」bouquets を入力、残り 12 件も登録） | |
| 2 | 商品登録（ミディ胡蝶蘭 ホワイト：商品名・商品番号・税込価格・在庫・カテゴリー・画像・説明・購入オプション）→ 残り 47 商品を CSV で一括登録 | **登録エラー**：1 件（2027 フラワーカレンダー）が「商品画像が商品画像フォルダにない」で未登録 → 画像をアップロードしてエラーの行だけ再登録 |
| 3 | トップページ：プレビューで現状を確認 → VS Code で BY SCENE のブロックを書いてクリエイターモードに反映 → プレビュー・スマートフォン表示 | **レイアウト崩れ**：カードが 1 列に縦に並び画像が画面いっぱいに → グリッドのクラス名の「-v2」が抜けていた → 直して反映 |
| 4 | 会員設定（ゲスト購入も可・ログイン ID はメールアドレス・生年月日を追加・ポイント 5%）→ ショップのヘッダーの「ログイン」「会員登録」 | |
| 5 | 決済設定（クレジットカード・Amazon Pay・PayPay）→ 配送設定（地域別の送料・最短お届け日） | **送料の誤り**：東京都が 1,320 円（「東京都下」のグループに東京都が入っていなかった）→ 移して 770 円 ／ **お届け日の誤り**：最短が 3 日後（11/10）→ ご利用ガイドの「4 日以降」に合わせて 11/11 |
| 6 | 注文フローの確認：商品ページで購入オプションを選んでカートへ → 管理画面に届いたテスト注文（送料 770 円・合計）を確認 → キャンセル | |

| 8 | 公開したショップ：トップ（BY SCENE → STYLE → おすすめ・特集）→ 胡蝶蘭の一覧 → 商品ページ | |

ミスが起きると字幕が赤い「⚠」表示になり、該当箇所に赤い枠が出ます。修正すると緑の「✓ 修正」に変わります。

### 日本語入力（Microsoft IME と同じ流れ）

カテゴリー名（胡蝶蘭・花束・ブーケ）と商品名（ミディ胡蝶蘭 ホワイト）は、ローマ字を 1 キーずつ入力 → 変換 → 確定 の流れで入力しています。
英数字（URL・商品番号・価格・送料など）は IME をオフ（半角/全角）にして入力し、画面下に押したキーを表示します。

## キー操作 / URL パラメータ

ほかのデモと同じです（`../../README.md`）。**Space** 再生 / 一時停止、**R** 最初から、**C** 字幕、**H** ヒント、`?t=秒` `?from=シーン番号` `?speed=1.3` `?captions=0`。

シーン番号：0 イントロ / 1 カテゴリ設定 / 2 商品登録 / 3 トップページ構築 / 4 会員登録・ログイン / 5 決済・配送設定 / 6 注文フローの確認 / 7 公開 / 8 公開ショップの確認

## 本番サイトとの同一性について

- ブラウザに表示されるショップ（プレビューと公開後、トップ・胡蝶蘭の一覧・商品ページ、PC / スマートフォン）は、公開中のショップをブラウザで開き、
  ショップのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/site-snapshot.js`・`assets/site/`。画像は WebP に変換）。スクリプト（計測タグ・チャット）は取り込んでいません。
- 「カードが縦に並ぶ」崩れは、取り込んだトップページの BY SCENE のグリッドのクラス名を一時的に書き換えて再現しています（`js/scenario.js` の `gridTypo`）。
  BY SCENE を追加する前のトップページは、そのブロックを隠して表示しています（`noScene`）。
- 管理画面の商品一覧・CSV・商品登録の商品名・価格・画像・カテゴリーは、ショップの公開ページ（すべての商品・各カテゴリーの一覧）から取得したものです（`tools/snapshots/makeshop-hanahiro/build-files.js`）。
  ショップの一覧ページは 1 ページ 48 件のため、48 商品を扱っています。

## 演出であるもの

- VS Code は今の既定の見た目です（`public/shared/vscode.css` / `vscode.js`）。プロジェクトのファイル（`data/products_hanahiro.csv`・`design/top.html`・`docs/shop-rules.md`）は、このデモのために作ったものです（中身はショップの公開データ）。
- 管理画面の処理の進み具合・件数・トースト・送料シミュレーション・お届け日のプレビューの表示は演出です。
- プレビューのアドレス（`/?preview=1`）は表示上のもので、makeshop のプレビュー URL の形式ではありません。

## サイトを更新した場合

```
npm run snapshot -- makeshop-hanahiro                 ショップの画面・画像を取り込み直す（tools/snapshot-store.js → 画像は WebP に変換）
node tools/snapshots/makeshop-hanahiro/build-files.js  商品・カテゴリー・トップページの HTML から js/files.js を作り直す
npm run timeline -- makeshop-hanahiro                  長さ・チャプターの測定とサムネイルの撮影
```

取り込むページ・取り除く要素は `js/config.js` の `snapshot` で設定します。

## makeshop の画面について（本物のものと、再現のもの）

- **ログイン画面は本物です**：https://console.makeshop.jp/login を取り込んだもの（`js/makeshop-login.js`・`assets/makeshop/login/`）で、旅わが・日清食品グループの動画と同じファイルです。ログインは送信していません。
- **ログイン後の管理画面は再現です**（アカウントが必要なため）。横長のロゴ（`assets/makeshop/ms-logo-typeA.svg`）・アイコン・テーマの色・タイトルの形式は、管理画面自身の公開 JavaScript から取ったものです（`js/makeshop-ui.js`）。
  メニューの大項目（ホーム・商品管理・注文管理・会員管理・ショップデザイン・分析・販促管理・アプリ管理・機能・設定）とグループの見出しは管理画面と同じですが、
  サブメニューの名前と各ページのフォーム・配置は再現です。
- 取り込み直し：`node tools/snapshots/tabisuruwagashi/capture-makeshop.js`（旅わが・日清食品グループの動画のフォルダに書き出します。このデモへは `js/makeshop-*.js` と `assets/makeshop/` をコピー）。

## ファイル構成

```

css/video.css         このデモだけの見た目（makeshop の管理画面）

js/files.js           商品・カテゴリー・トップページの HTML と、VS Code に表示するファイル（自動生成：tools/snapshots/makeshop-hanahiro/build-files.js）
js/apps.js            makeshop の管理画面（再現）の各ページ
js/makeshop-login.js  makeshop の本物のログイン画面（自動生成）
js/makeshop-ui.js     makeshop 管理画面の公開 JavaScript から取ったアイコン・色・タイトルの形式（自動生成）
js/makeshop-login-frame.js  ログイン画面の表示と入力
js/scenario.js        台本（シーンごとの操作・字幕・ミスと修正）
assets/site/          取り込んだ画像・フォント（自動生成）
assets/makeshop/      makeshop のログイン画面の画像・管理画面のロゴ（自動生成）
```
