# STUDIO 制作プロセス デモ — 有限会社長谷川興業（サイトのリニューアル）

> 一覧ページ（`/`）と再生ページ（`/watch/studio-ponpuya`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/studio-ponpuya/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME・通知）で、長さは 5 分 01 秒 です。

画面録画用のデモページです。STUDIO のエディタを模した画面で、有限会社長谷川興業のサイト（https://ponpuya.com/）のリニューアルを再生します。
まずリニューアル前のトップページのデザインとページ構成を確認し、トップページに「事業案内・保有車両・採用情報とメンバー紹介・お知らせ」を作り直します。
タブレット / スマホの表示を直し、プレビューで各ページへのリンクとお問い合わせ先（電話・フォーム・LINE・SNS）を確かめてから公開し、公開サイトを確認します。

Figma など別のツールでのデザイン工程は含みません（STUDIO での構築・リニューアルの記録です）。

## 録画の手順

吉武工務店・ワイエス建装の動画と同じです（`index.html` を Chrome で開く → F11 → 録画開始 → Space で再生。公開サイトがトップに戻って止まったら録画を停止）。

## 再生される内容

| STEP | 内容 | ミスと修正 |
| --- | --- | --- |
| 1 | 既存デザイン・ページ構成の確認（今のトップページを読み、レイヤー、引き継ぐフォントとカラー、会社案内・事業案内 2 ページ・採用・お知らせ・お問い合わせ・CMS のメンバー / お知らせのページを確認） | |
| 2 | 事業紹介（事業案内：背景写真、英字見出しを Outfit に、打設工事のカードを作って「詳しくはこちら」を /construction に。カードを複製して生コン販売・手配に書き換え） | |
| 3 | サービス・施工情報（保有車両：見出し、車両写真のスライダー、説明文、車種ごとの台数） | **入力ミス**：2t スクイズ車両を「9台」と入力（合計 12 台で、本文の「現在9台」と合わない）→ 車両リストで確かめて「6台」に修正 |
| 4 | 採用情報（写真とエントリーの入口）、メンバー紹介（CMS「メンバー」のスライダー）、お知らせ（CMS） | |
| 5 | タブレット / スマホ表示の確認 | **表示崩れ**：タブレットでヘッダーのリンクが表示されたままロゴと重なる → タブレットではリンクを非表示にし、メニューボタン（≡）に切り替え |
| 6 | プレビューでリンクとお問い合わせの動作確認（リンクにポインターを合わせ、Chrome の左下に出るリンク先で確認） | **リンクミス**：複製した「生コン販売・手配」の「詳しくはこちら」が /construction のまま → エディタでリンク先を /selling に変更し、プレビューで再確認 |
| 7 | 公開（カスタムドメイン ponpuya.com） | |
| 8 | 公開サイトの確認（生コン販売へのリンク、メンバー紹介、ページ全体） | |

ミスが起きると字幕が赤い「⚠」表示になり、該当箇所に赤い枠が出ます（プレビュー中はページの中に枠を表示）。修正すると緑の「✓ 修正」に変わります。

## 本物と再現の区別

本物（公開中のサイトから取り込んだもの。2026-11-19 取得）：

- キャンバスに組み上がるページ・プレビュー・公開サイト画面：公開中の https://ponpuya.com/ をブラウザで描画した DOM と STUDIO が生成した CSS をそのまま使っています。
  全シーンの実行後、キャンバスの DOM が取り込んだページと 1 文字単位で一致することを確認しています。
- 画像（メインビジュアル・事業案内・車両・採用・メンバー・SNS の写真、ロゴなど）、メンバー紹介とお知らせの CMS の内容、リンク先（各ページ・電話番号・LINE・TikTok・Instagram）は公開サイトのものです。
  車両とメンバーのスライダーで左右に複製されている写真も、取り込み時にすべて読み込んでいます。
- サイト独自の CSS（「COOLEST IN JAPAN」の流れる帯など）もそのまま使っています。
  サイトの CSS の 1 つに閉じていない `@media` があるため、スタイルシートごとに閉じてから 1 つにまとめています（本番のブラウザでの表示と同じ結果になります）。
- フォント（Noto Sans JP・Outfit）は本番と同じく Google Fonts から、右パネルの数値は CSS の実際の設定値です。ブレイクポイント（〜1140px / 〜840px / 〜540px）もこのサイトの CSS どおりです。
- ページ一覧（company・construction・selling・recruit・news・contact、CMS の member / news）は公開サイトのリンク先から作っています。
- ファビコンと OGP 画像はサイトのもの、エディタのロゴとタブのファビコンは STUDIO のものです。

再現（演出）：

- STUDIO のエディタ・プレビューの画面（パネル、表示 / 非表示やリンク先の選択、公開ダイアログなど）は簡易的な再現です（ログインが必要なため取り込めません）。
  プレビューの URL のプロジェクト ID は架空のもので、ぼかしています。
- 「リニューアル前」の状態は、公開中のトップページから今回作り直す 4 つのセクション（事業案内・保有車両・採用情報とメンバー紹介・お知らせ）を外したものです。
  リニューアル前のサイトそのものではありません（公開されていないため）。
- 要素を追加して文字を入力する順序や速さ、3 つのミスとその修正は演出です。タブレットの表示崩れは、本番の CSS の「リンクを非表示・メニューボタンを表示」をいったん外した状態です。
- プレビューで左下に出るリンク先の表示は、Chrome のリンクのステータス表示を再現したものです。

## 画面の環境

- Windows 11 のデスクトップで、STUDIO のエディタは最大化した Chrome のタブ（`app.studio.design`）で開いています。
  プレビュー（`preview.studio.site`）と公開後の「サイトを開く」（`ponpuya.com`）は同じウィンドウの新しいタブです
- タスクバーの時計は 2026/11/15 13:30 から、動画の経過時間に合わせて進みます（お知らせの最新 2023.09.07 と矛盾しない日付。サイトの取り込みは 11/19）

## サイトを更新した場合

```
npm run snapshot -- studio-ponpuya
```

`js/site-snapshot.js` と `assets/img/` が更新され、画像は WebP に変換されます。手作業が必要なものは吉武工務店の動画と同じです
（`js/editor.js` の `ASSETS` / `COLORS` / `FONT_VARS` / `FONT_LIST` / `pageHtml()`、`js/scenario.js` の `resolve()` と `JA`、`index.html` のページ一覧と CMS）。
台数の入力ミスの台本は `JA.num1`、リンク先の一覧は `LINKS` です。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | エディタ画面（これを開く） |
| `css/editor.css` | エディタの見た目（Chrome のリンク先表示を含む） |

| `assets/img/` | サイトの画像・ファビコン・OGP 画像 |
| `tools/snapshots/studio-ponpuya/` | スナップショット再取得用スクリプト（`npm run snapshot -- studio-ponpuya`。画像をすべて読み込ませてから取り込み、スタイルシートごとに括弧を閉じる） |
