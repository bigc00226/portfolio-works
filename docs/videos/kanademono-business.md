# 制作プロセス デモ — KANADEMONO for BUSINESS（kanademono.design/pages/business）法人向け見積もり・お問い合わせ機能

> 一覧ページ（`/`）と再生ページ（`/watch/kanademono-business`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/kanademono-business/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME）で、長さは 8 分 59 秒です。

画面録画用のデモページです。Windows 11 のデスクトップを模した画面上でマウスカーソルが自動で動き、
KANADEMONO の法人様窓口（https://kanademono.design/pages/business）にある **法人会員登録・法人価格・カンタン見積もり・請求書払い** を、
Shopify（Shopify Plus の B2B 機能）で作る工程を順番に再生します。

**要件整理 → 法人会員登録フォーム → 会社・法人カタログ → カンタン見積もり → 下書き注文・請求書 → 通知メール → 動作テスト**

## 最初に確認していただきたいこと

- kanademono.design は **Shopify（テーマは Impulse 2.4.0 をもとにした「kanademono-v2/main」）で運営されている実在のストア** です。
  このデモは、法人様窓口のサービスを Shopify の B2B 機能とアプリ（App Proxy）で作るとしたらどう進めるか、という **開発工程の再現** で、実際の開発作業の記録ではありません。
- **ストアの実データ**：法人様窓口のページ（PC / スマートフォン）、そこに書かれているサービスと条件（組み立て配送 25 万円以上・卸売取引 最大 15% オフ・請求書払い 月末締め翌月払い・
  カンタン見積もり・登録完了メール → ワンタイムパスワードでログイン の 3 ステップ）、商品ページ（THE TABLE / エルゴヒューマン）、商品名・販売元・価格・
  タグ（`TABLE【B2B】` `WORK CHAIR【B2B】` `【B2B】割引表記なし` など）は、公開中のストアから取得したものです。
- **再現用に作ったもの**：開発プロジェクトのコード（App Proxy のルート・テーマのセクション / スニペット / スクリプト・Flow の設定）、
  法人価格の計算（一律 15% オフ・「割引表記なし」は固定価格としたもの）、会社「株式会社テストラボ」とご担当者、見積書・下書き注文・注文・メールの内容と番号、
  支払い条件（Shopify の「30日以内」で再現。実際のストアは月末締め翌月払い）、スタイリング名、管理画面の各画面。
- **本物の画面**：顧客アカウントのログイン画面（https://shopify.com/25419644990/account → shopify.com/authentication/25419644990/login）は、
  ストアの実際のページを取り込んだものです（下の「本番サイトとの同一性について」）。見積書の PDF は実際に PDF ファイルとして作り、Chrome の PDF ビューアで開いた画面です。
- 公開ページの「法人様会員登録フォーム」の欄は、実際のストアでは外部のフォームが埋め込まれていて（取り込みの対象外）、デモではこの欄にデモで作ったフォームを表示しています。
- KANADEMONO（株式会社 KANADEMONO）は実在の企業です。このデモはローカルのファイルとしてだけ使ってください（Web に公開しないでください）。

## 録画の手順

1. `public/videos/kanademono-business/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/kanademono-business/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（ストアの画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「法人会員登録・法人価格・カンタン見積もり・請求書払いを Shopify の B2B 機能で実装」と出たら録画を停止

## 再生される内容

| STEP | 画面 | 内容 | ミスと修正 |
| --- | --- | --- | --- |
| 1 要件整理 | Chrome（公開中の法人様窓口）・VS Code | 法人会員限定サービスを確認し、`docs/requirements.md` に Shopify での実現方法（会社・カタログ・支払い条件・下書き注文・Flow）を書く | |
| 2 法人会員登録フォーム | VS Code ＋ ターミナル・テーマエディタ・Chrome（127.0.0.1:9292） | テーマのセクション `b2b-register.liquid`、App Proxy `/apps/b2b/register`（`companyCreate`）、`shopify app dev` / `theme dev`、テーマエディタでテンプレートにセクションを追加、開発ストアで送信テスト | **入力漏れ**：会社名が空でも申請が通り「名称なし」の会社ができた → `required` と App Proxy 側のチェック（422）を追加、空だとエラー表示・入力すると受付 |
| 3 会社・法人カタログ | Chrome（管理画面・開発ストア）・VS Code | テストの会社を削除、申請された会社にカタログ「法人卸 15%OFF」（「割引表記なし」は固定価格）、支払い条件 30日以内、連絡先のロール、商品ページの法人価格を確認、承認して登録完了メール | **表示の誤り**：タグ「【B2B】割引表記なし」のチェアに「卸売 15%OFF」が出る → スニペット `b2b-price` に `unless product.tags contains '【B2B】割引表記なし'` |
| 4 カンタン見積もり | VS Code ＋ ターミナル・Chrome（PDF・DevTools） | App Proxy `/apps/b2b/quote`（`draftOrderCreate` → 見積書 PDF）、テストスクリプトで見積もり、商品ページの「この商品で見積書を作成」ボタン（`b2b-quote.js`）とネットワークの確認 | **価格の誤り**：見積書が通常価格のまま（合計 ¥1,304,500）→ 下書き注文に `purchasingEntity`（会社・ロケーション・連絡先）を指定 → 法人価格（¥1,199,425） |
| 5 下書き注文・請求書 | Chrome（管理画面） | 見積もりの下書き注文（法人価格・会社・支払い条件）→ 請求書を送信 → リンクからの注文が支払い期日つき（請求書払い）に | |
| 6 通知メール | Chrome（設定 › 通知・Flow） | 「B2B アクセスのメール」（登録完了メール）にサービスの案内を追加、Flow で「会社が作成された」→ 担当者へ申請内容のメール | |
| 7 動作テスト | Chrome（メール・ログイン・PDF・デバイスモード） | 担当者へのメール、登録完了メール → ワンタイムパスワード（確認コード）でログイン、見積書メールと PDF、スマートフォン幅の登録フォーム・法人価格 | |
| 公開ページの確認 | Chrome | 法人様窓口（ABOUT・SERVICE・REGISTRATION FORM・CONTACT）、ログインしていない人の商品ページは通常価格のまま | |

### 日本語入力（Microsoft IME と同じ流れ）

要件のメモ、コードのコメント・文字列、フォームへの入力（会社名・部署名など）、メールのテンプレートの日本語は、ローマ字を 1 キーずつ入力 → 変換 → 確定 の流れで入力しています。
英数字は IME をオフ（半角/全角）にして入力し、画面下に押したキーを表示します。

## キー操作 / URL パラメータ

ほかのデモと同じです（`../../README.md`）。**Space** 再生 / 一時停止、**R** 最初から、**C** 字幕、**H** ヒント、`?t=秒` `?from=シーン番号` `?speed=1.3` `?captions=0`。

## 本番サイトとの同一性について

- ブラウザに表示されるストア（開発環境 127.0.0.1:9292・本番 kanademono.design、法人様窓口と 2 つの商品ページ、PC 幅 1920px / スマートフォン幅 390px）は、
  公開中のストアをブラウザで開き、ストアのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/site-snapshot.js`・`assets/site/`）。
  スタイルシートは本番のファイルのまま、画像はその幅で表示されていたサイズのものです。スクリプト（計測タグ・アプリ・埋め込みのフォームや動画）は取り込んでいません。
- 取り込んだ画面に足しているもの：法人様会員登録フォームの欄に入れたデモのフォーム、法人会員でログインしたときの「法人価格」の枠と見積書ボタン（`js/apps.js` の `putForm` / `putPrice`）。
- 管理画面の商品名・販売元・価格・画像、カタログの商品一覧は、ストアの公開商品データ（`/products.json`）から取得したものです。
- **顧客アカウントのログイン画面**（ステップ 7）は、ストアの実際のログインページ（Shopify の新しい顧客アカウント、ja-JP）を Chrome で開き、スクリプトが動いた後の画面を
  そのまま取り込んだものです（`js/account-snapshot.js`、`tools/snapshots/kanademono-business/capture-account.js`）。マークアップ・2 つのスタイルシート（バイト単位でそのまま）・
  ページが CSSOM で足しているスタイル・「shop で続行」ボタン（`<shop-login>` の Shadow DOM）・Web フォント GT Standard（`assets/account/fonts/`）・
  入力欄とボタンにフォーカスがあるときの見た目（実際のページで測ったもの）まで本物です。メールアドレスは実際の入力欄に入力し、浮き上がるラベルもページ自身の CSS で動きます。
  取り込みでは何も送信していません（メールアドレスの送信・ログインはしていません）。ワンタイムの値（state など）は取り除いています。
- **確認コードの入力画面** は、取り込むには実在のアドレスへコードを送信する必要があるため取り込んでいません。取り込んだログインページの同じ部品に、
  ページ自身の日本語の文言（ページが読み込む ja ロケールの「コードを入力」「{{email}}に送信されました」「6桁のコード」「別のメールアドレスでログインする」）を当てて表示しています。
  入力欄・ボタンの配置は推定です。
- **見積書の PDF**（`assets/pdf/quote-D1023.pdf` ほか 3 つ）は、動画のデータ（ストアの商品・価格。「割引表記なし」のチェアは固定価格）から Chrome で A4 の PDF に出力した本物の PDF です。
  画面はその PDF を、インストールされている Chrome（157）の PDF ビューアで開き、この動画のブラウザのページ領域（1920×947）で撮影したものです（ツールバー・サムネイル・ページの描画まで Chrome そのもの）。
  ポインターが指す位置（表・お見積金額・合計・備考）は、PDF のレイアウトから計算しています（`js/quote-pdfs.js`、`tools/snapshots/kanademono-business/build-quote-pdfs.js`）。

## 演出であるもの

- **画面の環境**：VS Code は今の既定の見た目です（Dark Modern テーマ、VS Code 自身のアイコン codicon、Seti のファイルアイコン、ミニマップ。`public/shared/vscode.css` / `vscode.js`）。
  Shopify の管理画面は左上のロゴとタブのファビコンが本物です（`npm run favicons`）。ファビコンのないページ（開発サーバーなど）のタブには Chrome 本体のアイコンを表示しています。

- Shopify の管理画面・テーマエディタ・Flow・メール（Gmail。ログインが必要なため取り込めません。タブのアイコンは本物の Gmail のもの）は **見た目を似せた再現** です。
- ログイン後の顧客アカウントの「注文」画面は、ログインしないと開けないため再現です（フォント・文字色・線の色などは、取り込んだログインページで測った値に合わせています）。
- ターミナルの出力（`shopify app dev` / `theme dev`、テストスクリプトの結果）は、実際のコマンドの出力の形式に合わせて表示しています。
- 見積書のレイアウト・番号、会社 ID・注文番号・日時、確認コードは架空のものです。

## サイトを更新した場合

```
npm run snapshot -- kanademono-business      ストアの画面・画像・商品データを取り込み直す（tools/snapshot-store.js → 画像は WebP に変換）
npm run timeline -- kanademono-business     長さ・チャプターの測定とサムネイルの撮影
```

取り込む内容（ページ・商品・取り除く要素）は `js/config.js` の `snapshot` で設定します。

ログイン画面と見積書の PDF は、それぞれ次のスクリプトで作り直せます（作り直したら `node tools/webp.js kanademono-business` で画像を WebP に）。

```
node tools/snapshots/kanademono-business/capture-account.js     ログイン画面を取り込み直す（js/account-snapshot.js・assets/account/fonts/）
node tools/snapshots/kanademono-business/build-quote-pdfs.js    見積書の PDF を作り、Chrome の PDF ビューアで撮影し直す（assets/pdf/・js/quote-pdfs.js）
```
ファビコンは `assets/favicon-32.webp`（取り込みの対象外のため、手動で保存したもの）です。
