# makeshop クリエイターモード移行デモ — 旅するように和菓子と出逢う

> 一覧ページ（`/`）と再生ページ（`/watch/tabisuruwagashi`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/tabisuruwagashi/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME・通知）で、長さは 5 分 14 秒 です。

画面録画用のデモページです。ブラウザ（Chrome 風）の画面上でマウスカーソルが自動で動き、
「旅するように和菓子と出逢う」（https://www.tabisuruwagashi.com/）のトップページを、
makeshop の **ベーシックモード → クリエイターモード** へ移行する作業の核心部分を順番に再生します。

デザインセット作成 → ヘッダー / フッターのモジュール化 → トップページ HTML のクリエイターモードタグへの書き換え
→ CSS / JS → プレビューで確認・修正 → スマホ幅の確認 → ショップに適用 → 公開ショップの確認、までの流れです。

## 録画の手順

1. `public/videos/tabisuruwagashi/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/tabisuruwagashi/index.html でも可）
   - フォント（Google Fonts）の読み込みにインターネット接続が必要です
   - 開いた直後の数秒で、ショップの画像・フォントを先読みします（タイトル画面が表示されたら準備完了）
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始（右下のキー操作ヒントは再生開始と同時に消えます）
5. 公開ショップがトップに戻り、字幕「移行が完了」が消えたら録画を停止

再生時間は標準速度で **5 分 14 秒** です（字幕・入力・ミスの場面を含む）。短くしたい場合は下の `speed` を使ってください。

ミスが起きると字幕が赤い「⚠」表示になり、該当箇所に赤い枠が出ます。修正すると緑の「✓ 修正」に変わります。

4 つのミスの修正結果は、本番サイトの実際の記述と一致しています
（`<{/section}>` の位置、`const baseUrl = 'https://www.tabisuruwagashi.com/blog/';`、
ヘッダーの `<style>` 内のコメント「スマホ：アイコンが1つ増えるため間隔を詰める（幅360pxでもロゴと重ならない）」と `gap: 8px`）。

### 日本語入力の再現

文字入力は、実際の Windows（Microsoft IME）での操作と同じ流れで再生されます。

- ローマ字を 1 キーずつ入力 → かなに変わっていく入力中の文字（点線の下線）
- 入力中は予測候補（ヒント）のウィンドウが表示され、1 キーごとに読みに合う候補だけに絞り込まれます
- Space で変換（文節ごとの下線、太い下線が変換中の文節）、2 回目の Space で変換候補の一覧 → Enter で確定
- 「旅わが」の「わが」のように、変換せずに Enter でかなのまま確定する場面もあります
- コードや数字は「半角/全角」キーで直接入力に切り替えて入力
- 画面下に、押しているキー（ローマ字・Space・Enter・Shift・End など）と IME の状態（あ / A）を表示
- 一度確定した変換は IME が覚えます（「新着賞品」を直すときは、学習した「賞品」が先頭に出て、もう 1 回 Space で「商品」）

日本語を入力する場面：デザインセット名「旅わが 2026」、モジュール名「ヘッダー」「フッター」、
見出し「新着商品」（誤変換とその修正）、ヘッダーの CSS コメント。

## キー操作

| キー | 動作 |
| --- | --- |
| Space | 再生開始 / 一時停止 |
| ← / → | 5 秒戻る / 進む |
| R | 最初からやり直す |
| C | 字幕（STEP 表示）の表示 / 非表示 |
| H | キー操作ヒントの表示 / 非表示 |

## URL パラメータ

`index.html?speed=1.3&captions=0` のように指定します。

| パラメータ | 内容 |
| --- | --- |
| `speed=1.3` | 再生速度（1 が標準。ミスを直した後の緑の字幕は、読める長さのまま表示されます） |
| `from=4` | 指定したシーンから再生。ページを開くと、それより前のシーンを「準備中…」の表示の裏で進めて組み立て、そのシーンの開始状態で止まります。「準備中…」が消えてから録画を開始し、Space で再生 |
| `t=83.5` | 指定した時刻（秒）まで画面の裏で進めて、その場面で止まります（`play=1` を付けるとそのまま再生） |
| `embed=1` | 再生ページの中で使う表示（キー操作ヒントなどを出さない）。再生ページから開いたときは自動で付きます |
| `to=4` | 指定したシーンを再生し終えたところで止める |
| `captions=0` | 字幕なしで再生（ミスの赤枠・緑枠は表示されます） |
| `autoplay=1` | 準備ができてから約 1.5 秒後に自動で再生開始 |

シーン番号は上の表の「シーン」列（0〜9）です。例：`index.html?from=6&to=7` でプレビュー確認とスマホ確認だけ。

## makeshop の画面について（本物のものと、再現のもの）

- **ログイン画面は本物です**：https://console.makeshop.jp/login をブラウザで表示した結果（Vue / Vuetify のマークアップ、GMO グループのヘッダー・フッター、makeshop のロゴ）を、
  スタイルシート・画像ごとそのまま取り込んだものです（`js/makeshop-login.js`・`assets/makeshop/login/`。スクリプト・計測タグ・チャットは取り除いています）。
  入力欄の見た目の変化（フォーカス・入力済み）は、ページ自身の Vuetify のクラス（`v-field--focused` など）を付け外ししています（`js/makeshop-login-frame.js`）。
  ログインは送信していません（どこにもログインしていません）。
- **ログイン後の管理画面は再現です**：中に入るにはアカウントが必要なため、公開されている材料で作り直しています。
  管理画面自身の公開 JavaScript（console.makeshop.jp/assets/*.js）から取ったもの：横長のロゴ（`assets/makeshop/ms-logo-typeA.svg`）、
  アイコン（`/src/assets/icons/*.svg`）、テーマの色（nextEcTheme：#4558c4 ほか）、ページのタイトルの形式（「〇〇 - makeshop byGMO」）、
  メニュー・グループの名前（「日々のショップ運営をスムーズにする」「便利な機能を追加する」「アプリ管理」「機能・設定」など）、
  アドレス（`/dashboard`、`/shop-design/ms-design-creator`、`/shop-design/ms-design-creator/<id>/pages`・`/modules`、`/shop-design/ms-design-basic`）と
  画面名（テンプレート選択・編集・ページの編集・モジュール一覧）。文字はログイン画面と同じ「メイリオ, Meiryo, …」の指定です
  （この PC のように Meiryo が入っていない環境では、ＭＳ ゴシックの代わりに Yu Gothic UI で表示します）。
  レイアウト・カードの中身・クリエイターモードの編集画面・旧デザイン編集画面は、公式マニュアルに沿った再現です。
- GMO グループのヘッダーはログイン画面だけに出ます（管理画面のアプリがログイン画面を離れるときに外しているため、管理画面には付けていません）。
- 取り込み直し：`node tools/snapshots/tabisuruwagashi/capture-makeshop.js`（日清の動画の makeshop の画面も同時に更新）。

## 本番サイトとの同一性について

- プレビューと公開ショップの画面は、公開中のトップページをブラウザで表示した結果の DOM
  （makeshop が出力した HTML・クラス構成、WordPress から読み込まれる特集・JOURNAL・お知らせ、レビューウィジェット）を、
  PC 幅（1920px）とスマートフォン幅（360px）でそのまま取得したものです。
  スタイルシートも本番のファイル（page.css = 全ページ共通 + トップ、system CSS、アプリの CSS）をそのまま使い、
  画像は `assets/site/` に保存した本番の画像を参照しています（変えているのは画像の参照先だけです）。
- 取得時に、ページ内の `<script>`（計測・広告・ヒートマップなどのタグを含む）は取り除いています。録画中に本番の計測へアクセスが送られることはありません。
  メインビジュアルのスライド（3 秒表示・1 秒で切り替え・ループ）、スクロールでのナビの隠れ方、ページトップボタンは、ショップのスクリプトと同じ動きを小さな再現コードで動かしています。
- コードエディタに表示される CSS / JavaScript は、本番で配信されている page.css / page.javascript の内容そのものです
  （全ページ共通 = ビルド済みのバンドル、トップ = WordPress 読み込み処理）。
- トップページの HTML とヘッダー / フッターのモジュールは、本番で配信されている HTML から組み立てています。
  makeshop が出力する部分（タイトル・説明文・CSS / JS の URL・makeshop.head / body_top / body_bottom の出力・メインビジュアル・
  新着商品 / 人気ランキングの一覧）をタグに戻したもので、タグの部分に makeshop の出力を当てはめ直すと本番の HTML と一致することを確認済みです
  （`tools/snapshots/tabisuruwagashi/test/tpl-check.js`）。
- 全シーンを再生した後のエディタの中身（トップ HTML / JS、全ページ共通 CSS / JS、ヘッダー / フッターモジュール）は、上の組み立てた内容と 1 文字単位で一致します
  （`tools/snapshots/tabisuruwagashi/test/run.js` が再生後に照合）。

## 演出であるもの

- ログイン後の管理画面・クリエイターモードの編集画面・旧デザイン編集画面・プレビュー表示は、makeshop での作業の流れを伝えるための再現です（上の「makeshop の画面について」）。
  公式マニュアルの画面（デザインセット一覧、ベーステンプレートの選択、コード編集画面のページ一覧・モジュール管理）に沿って作っていますが、
  細部まで同一ではありません。ベーステンプレートのサムネイルは図形で描いたものです。
- ショップのテンプレートの実際のソースは公開されていないため、エディタ上のクリエイターモードタグの書き方（変数名など）は、
  公式タグリファレンスの書式に沿った再現です。実際のソース（デザインセットのエクスポートなど）をいただければ差し替えられます。
- 旧デザイン（ベーシックモード）編集画面に表示している HTML は、移行元として本番の HTML からクリエイターモードのタグを外したものです。
- 保存エラーの文言、プレビューの URL と上部のバー、デザインセット適用の確認ダイアログの文言は、流れを伝えるための再現です。
  コンソールのエラー（404 と JSON の構文エラー）は、本番の JavaScript で baseUrl の「/」が抜けた場合に Chrome が出す内容に合わせています。
- 4 つのミスと、その起き方（誤変換・閉じタグ忘れ・URL の「/」抜け・360px での重なり）は演出です。

## サイトを更新した場合

本番サイトの内容を変更したら、スナップショットを取り直すとデモにも反映されます（Node.js 18 以上と Chrome が必要）。

```
npm install                              （初回のみ。プロジェクトのフォルダで実行）
npm run snapshot -- tabisuruwagashi
node tools/snapshots/tabisuruwagashi/capture-makeshop.js     makeshop のログイン画面・管理画面の素材（ロゴ・アイコン・色）
```

`js/site-snapshot.js` と `assets/site/` が更新されます（数分かかります）。

自動で反映されるもの：

- プレビュー・公開ショップの画面（DOM・CSS・画像、PC / スマホ）
- エディタに表示される CSS / JavaScript、トップ HTML、ヘッダー / フッターモジュール、旧デザイン編集画面の内容
- 新着商品の 1 件目（ループ化の場面で書き換える値）

手作業での修正が必要になる場合：

- ページの区切りの目印（`<!-- ▼ヘッダー追加分のスタイル`、`<!--フッター-->`、`<!-- 新着アイテム -->`、`<!-- 人気ランキング -->`、
  `</div><!--/ l-wrapper -->`、`<!-- End Google Tag Manager -->`）を変えた場合：`js/template.js` の目印を合わせる
  （見つからないと準備の段階でエラーになります）
- ヘッダーの `<style>` 内の「スマホ：…」のコメントや `gap: 8px` を変えた場合：`js/scenario.js` の `JA.gap` を合わせる
- トップページ用 JavaScript の `const baseUrl = '…';` を変えた場合：`js/scenario.js` の `BAD_BASE` を合わせる
