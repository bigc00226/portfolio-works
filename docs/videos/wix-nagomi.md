# 制作プロセス デモ — Nagomi Nature Connections（www.nagomi-nc.com）Wix サービス紹介サイト・予約導線の制作

> 一覧ページ（`/`）と再生ページ（`/watch/wix-nagomi`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/wix-nagomi/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME）で、長さは 5 分 0 秒です。画面の日付は 2026/11/12（木）14:20〜。

画面録画用のデモページです。Windows 11 のデスクトップを模した画面上でマウスカーソルが自動で動き、
西湖・本栖湖でカヤック・SUP の体験ツアーを行う Nagomi Nature Connections（https://www.nagomi-nc.com/）の
**サービス紹介サイトと、各ページから予約リクエストフォームへつなぐ予約導線を Wix で作る工程** を順番に再生します。

これは **1 枚のランディングページ（LP）ではありません**。ツアー紹介（カヤック・SUP・樹海探検・富士下山）・NNC の紹介・Q&A・ブログなど
複数のページで構成し、どのページからも予約リクエストフォームに進めるようにしたサービス紹介型のサイトです。
予約はその場で確定するしくみ（予約システム）ではなく、フォームでリクエストを受けてから担当者が空き状況を確認して連絡する流れです。

**サイト構成・メニュー → メインビジュアル・写真 → 体験プログラム → 特徴・FAQ・ブログ → 予約リクエストフォーム → スマホ対応 → 公開**

## 最初に確認していただきたいこと

- www.nagomi-nc.com は **Wix で作られて公開中の実在のサイト** です（ページの generator は「Wix.com Website Builder」）。
  このデモは「このサイトを Wix で作るとしたらどう進めるか」という **制作工程の再現** で、実際の制作作業の記録ではありません。
- **本物（公開サイトから取り込んだもの）**：エディタのキャンバスに表示されるページと公開後に開くサイトは、公開中のサイトをブラウザで開いてスクリプトが動いた後の画面を
  **そのまま取り込んだもの** です（TOP・SUP体験・カヤック体験・Q&A・おおさん日記・予約リクエストフォームの 6 ページ、PC 幅 1920px / スマートフォン幅 390px。
  文章・写真・プランと料金・ボタン・メニュー・予約リクエストフォームの項目と選択肢・フォント、タブのタイトルとファビコンもサイトのもの）。
  動画で入力するキャッチコピー・料金（7,480 円）・送信ボタンの文言（予約リクエスト送信する）・フォームの選択肢（西湖SUPレンタル）・SEO タイトルも公開サイトにある実際の文言です。
- **取り込みは閲覧だけ**：公開サイトのフォームからは何も送信していません（予約リクエスト・問い合わせ・ログインは一切していません）。動画の中でもフォームは表示するだけです。
- **再現（Wix のエディタ）**：Wix のエディタはログインが必要なため、画面は **見た目を似せた再現** です（`public/shared/wix/`。`wix-light-op` と共通）。
  左上のロゴ・タブのファビコン・Wix のブルー（#116dff）は本物です（`npm run favicons`）。パネル（ページとメニュー・メディア・スライドショー・リンク・フォーム・ブログの表示・
  モバイルで非表示の要素・SEO）、公開のダイアログ、エディタの URL のサイト ID は再現用に作ったものです。
- **作ったもの**：アップロードする写真のファイル名とフォルダ、フォームの自動返信の本文、ページを追加する順序、作業の日時。
  ヘッダーの「ツアー紹介」のドロップダウンの中身（公開サイトではスクリプトで開くため取り込めない）は、サイトのツアー一覧から並べています。
- 画面の日付（11/12）より後の日付の記事・お知らせは表示しない設定にしています（状態 `future`。取り込んだ時点では該当なし）。
- Instagram の投稿・Google マップ・旅色の動画は `<iframe>` の埋め込みで取り込めないため、空いた枠を畳んでいます（状態 `noEmbeds`）。
- Nagomi Nature Connections は実在の事業者です。このデモはローカルのファイルとしてだけ使ってください（Web に公開しないでください）。

## 録画の手順

1. `public/videos/wix-nagomi/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/wix-nagomi/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（サイトの画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「… 予約リクエストフォームまでつなぐサービス紹介サイトが完成」と出たら録画を停止

### 日本語入力（Microsoft IME と同じ流れ）

ページ名・キャッチコピー・フォームの選択肢・自動返信の本文・送信ボタン・SEO タイトルは、ローマ字を 1 キーずつ入力 → 変換（「西湖」は変換候補から選ぶ）→ 確定 の流れで入力しています。
英字と数字（SUP・7,480・1）は直接入力、SEO タイトルの後半（サイト名）はトップページのタイトルからコピーして貼り付けています。

## 本番サイトとの同一性について

- キャンバスと公開サイトのページは `tools/snapshot-store.js` で取り込んだものです（`js/site-snapshot.js`・`assets/site/`。表示は `public/shared/kit/store-frame.js`）。
  Wix がページに書き出した HTML とスタイルをそのまま使い、画像はそのページの幅で選ばれたもの、フォントはサイトが使う Wix のフォント（woff2）です。
- 「まだ作っていない」状態（TOP のセクション・スライドショーの写真）は、取り込んだページの一部を隠すことで表し、作る操作に合わせて元に戻しています
  （`js/scenario.js` の `homeBuild` / `homeRest` / `heroNoImg`）。入力する文言は、要素を空にしてから入力し、入力後にページ本来のマークアップ（文字の大きさの違いなど）に戻しています。
  モバイルで非表示のセクション（`spNoCta`）はそのセクションを隠して再現しています。
- プレビューでボタンを押したときのページの切り替わりは、取り込んだ別のページを表示することで表しています。
- アップロードでメディアに入る写真は、取り込んだページの写真です。

## 演出であるもの

- Wix のエディタの画面全体（トップバー・左のツールバー・選択枠と浮かぶツールバー・各パネル・プレビュー・公開のダイアログ）。キャンバスはページを 1920px で描いて、エディタの幅に縮小して表示しています。
- 制作の順序と所要時間（実際の制作は数日〜数週間）。各プランのボタンのうち一部は、同じ手順の繰り返しとして結果だけを示しています。

## サイトを更新した場合

```
npm run snapshot -- wix-nagomi     サイトの画面・画像・フォントを取り込み直す（tools/snapshot-store.js → 画像は WebP に変換）
npm run timeline -- wix-nagomi     長さ・チャプターの測定とサムネイルの撮影
```

取り込むページと取り除く要素は `js/config.js` の `snapshot` で設定します。取り込みはページを開いて見るだけで、フォームは送信しません。
Wix のフォントは woff2 / woff / ttf の 3 形式が取り込まれます。ブラウザが使うのは woff2 だけなので、取り込み後に
`assets/site/static.wixstatic.com/ufonts/*/woff` と `*/ttf` のフォルダ（同じフォントの woff2 があるもの）を削除しています。

