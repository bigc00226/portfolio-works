# 制作プロセス デモ — GREEN BASE（green-base.jp）テーマ選定とメタフィールドによるカスタマイズ

> 一覧ページ（`/`）と再生ページ（`/watch/green-base`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/green-base/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME）で、長さは 6 分 14 秒です。

画面録画用のデモページです。Windows 11 のデスクトップを模した画面上でマウスカーソルが自動で動き、
観葉植物の通販 GREEN BASE（https://green-base.jp/）の **Shopify テーマの選定と、メタフィールド（メタオブジェクト）を使った商品ページのカスタマイズ** を順番に再生します。

**テーマ選定 → メタオブジェクト定義 → 商品データ入力 → Liquid カスタマイズ → テーマエディタで接続 → レスポンシブ確認**

## 最初に確認していただきたいこと

- green-base.jp は **Shopify（テーマは Flow 39.9.1）で運営されている実在のストア** です。
  このデモは「テーマを選び、植物ごとの育て方をメタフィールドで管理して商品ページに表示する」としたらどう進めるか、という **制作工程の再現** で、実際の制作作業の記録ではありません。
- **ストアの実データ**：商品（パキラ S × ロムS ベージュ ほか鉢違いの商品）・価格・説明文・タグ（`LIGHT_` `SIZE_` `DIFFICULITY_` `INTERIOR_` `MERIT_`）、
  商品ページの育て方の内容（日当たり・みずやり・原産地・花言葉・気温・注意・ペット・赤ちゃん）とその HTML のクラス名（`p-detail__content` `l-detail__block__icon` `l-icon__…`、セクション名 `parts_item_detail`）、
  使われているテーマ（Flow）、ブラウザに表示されるストアの画面（PC / スマートフォン）は、公開中のストアから取得したものです。
- **テーマストアの画面（本物）**：テーマ選定の場面の Shopify テーマストア（themes.shopify.com、日本語）は、公開ページを 2026-11-17 に取り込んだ本物の画面です
  （業種「ガーデン」で絞り込んだ一覧 29 件・ヘッダーの検索と候補・Flow のページとデスクトップ / モバイル版のプレビュー、価格 $320・評価 91%・作成者 Eight Themes・機能の一覧）。
  実際の絞り込みでは Flow は「ガーデン」に含まれない（業種「食料品・飲料」のテーマ）ため、台本は「ガーデンの一覧で見本を比べる → メモの候補 Flow をテーマ名で検索」の流れにしています。
- **再現用に作ったもの**：メタオブジェクト「植物」（タイプ `plant`）とフィールドのキー、商品メタフィールド `custom.plant`、セクションの Liquid とスタイル
  （ストアの実際のテーマのソースは公開されていないため、同じマークアップを出力するように書いたもの）、テーマ選定のメモ、作業の日時。
- GREEN BASE は実在のストアです。このデモはローカルのファイルとしてだけ使ってください（Web に公開しないでください）。

## 録画の手順

1. `public/videos/green-base/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/green-base/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（ストアの画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「テーマ選定とメタオブジェクトによる商品ページのカスタマイズが完了」と出たら録画を停止

## 再生される内容

| STEP | 画面 | 内容 | ミスと修正 |
| --- | --- | --- | --- |
| 1 テーマ選定 | VS Code・Chrome（テーマストア・管理画面） | 要件のメモ（写真を大きく・条件で探せる・育て方）→ テーマストア（本物の画面）で業種「ガーデン」の見本を比べ、メモの候補 Flow を検索 → Flow のページで機能の一覧・モバイル版のプレビューを確認 → 「テーマを試す」でテーマライブラリに追加 | |
| 2 メタオブジェクト定義 | Chrome（設定 → カスタムデータ） | メタオブジェクト「植物」（`plant`）に 7 つのフィールド（花言葉は 1 行テキストのリスト）、商品メタフィールド「植物」（`custom.plant`・メタオブジェクト参照） | |
| 3 商品データ入力 | Chrome（コンテンツ・商品） | エントリ「パキラ」を作成（ケアカードと同じ文面）、商品「パキラ S × ロムS ベージュ」で参照、鉢違いのパキラを一括編集で同じエントリに | |
| 4 Liquid カスタマイズ | VS Code ＋ ターミナル | `sections/parts-item-detail.liquid`（ABOUT・日当たり・みずやり・原産地 … をループで出力、schema の設定「植物」はメタオブジェクト型）、`shopify theme dev --theme-editor-sync` | |
| 5 テーマエディタで接続 | Chrome（テーマエディタ） | 商品テンプレートにセクション「植物の詳細」を追加 → 設定「植物」を動的ソース「商品 › 植物」に接続 | **表示されない**：設定が空で育て方が出ない → 動的ソースに接続。**表示ミス**：花言葉が `["快活","勝利"]` → `.list?` で判定して `join: '、'` →「快活、勝利」 |
| 6 レスポンシブ確認 | テーマエディタ（モバイル）・VS Code | 幅 390px で確認、`shopify theme push`、Flow を公開 | **表示崩れ**：一覧の幅を 620px に固定していて文章が右で切れる → `width: 100%; max-width: 620px;` |
| 公開ストアの確認 | Chrome | 商品ページの育て方、トップページ | |

### 日本語入力（Microsoft IME と同じ流れ）

管理画面の名前（植物・日当たり・パキラ・中南米・快活 …）、Liquid のコメントとラベルの日本語は、ローマ字を 1 キーずつ入力 → 変換 → 確定 の流れで入力しています。
長い文章（育て方の説明）は、ケアカードのデータからコピーして貼り付けています。

## 本番サイトとの同一性について

- テーマストアは、公開ページをブラウザで開き、サイトのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/themestore-snapshot.js`・`assets/themestore/`、表示は `js/themestore-frame.js`）。
  取り込むときに検索を開いて「flow」と入力した状態の画面を保存し、検索を閉じた一覧・空の検索欄・入力後の候補は、サイト自身のクラス（`theme-search-overlay--is-open` など）の付け外しで表示しています。
  Flow のページのプレビュー（デモストアの `<iframe>`）は、その時点の表示のスクリーンショットに置き換えています。取り込み直し：`node tools/snapshots/green-base/capture-themestore.js` → `node tools/webp.js green-base`。
- ブラウザに表示されるストア（テーマエディタのプレビュー・本番 green-base.jp、トップページと商品ページ、PC 幅 1920px / スマートフォン幅 390px）は、
  公開中のストアをブラウザで開き、ストアのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/site-snapshot.js`・`assets/site/`）。
- 「セクションがない」「ABOUT だけ」「花言葉がリストのまま」「右にはみ出す」状態は、取り込んだ画面の一部を隠す・文字を差し替える・幅を固定するスタイルを足すことで再現しています（`js/scenario.js` の `noDetail` / `aboutOnly` / `hanaJson` / `spOverflow`）。
- 管理画面の商品名・説明・価格・画像・タグは、ストアの公開商品データ（`/products.json`）から取得したものです。

## 演出であるもの

- **画面の環境**：VS Code は今の既定の見た目です（Dark Modern テーマ、VS Code 自身のアイコン codicon、Seti のファイルアイコン、ミニマップ。`public/shared/vscode.css` / `vscode.js`）。
  Shopify の管理画面は左上のロゴとタブのファビコンが本物です（`npm run favicons`）。ファビコンのないページ（開発サーバーなど）のタブには Chrome 本体のアイコンを表示しています。

- 管理画面・テーマエディタは **見た目を似せた再現** です（管理画面のテーマライブラリのテーマの画像は図形です）。テーマストアで入力した「flow」の文字は、入力欄の上に重ねて描いています。
- ターミナルの出力（`shopify theme dev` / `push`）は、実際のコマンドの出力の形式に合わせて表示しています。
- テーマのファイル（`sections/` `snippets/` など）は説明のための最小限のもので、Flow やストアの実際のソースではありません。

## サイトを更新した場合

```
npm run snapshot -- green-base      ストアの画面・画像・商品データを取り込み直す（tools/snapshot-store.js → 画像は WebP に変換）
node tools/snapshots/green-base/capture-themestore.js   テーマストアの画面を取り込み直す（続けて node tools/webp.js green-base）
npm run timeline -- green-base     長さ・チャプターの測定とサムネイルの撮影
```

取り込む内容（ページ・商品・取り除く要素）は `js/config.js` の `snapshot` で設定します。

```

```
