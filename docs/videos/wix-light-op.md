- **本物（公開サイトから取り込んだもの）**：エディタのキャンバスに表示されるページと、公開後に開くサイトは、公開中のサイトをブラウザで開いてスクリプトが動いた後の画面を

  文章・写真・ロゴ・メニュー・会社情報の表・お問い合わせフォームの項目・フォント、タブのタイトルとファビコンもサイトのもの）。

## 録画の手順

1. `public/videos/wix-light-op/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/wix-light-op/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（サイトの画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「製造業の企業ホームページ … が完成」と出たら録画を停止

## 本番サイトとの同一性について

- キャンバスと公開サイトのページは `tools/snapshot-store.js` で取り込んだものです（`js/site-snapshot.js`・`assets/site/`。表示は `public/shared/kit/store-frame.js`）。
  Wix がページに書き出した HTML とスタイル（インラインの `<style>`）をそのまま使い、画像はそのページの幅で選ばれたもの、フォントはサイトが使う Wix のフォント（woff2）です。
- 「まだ作っていない」状態（空のページ・ロゴのないヘッダー・背景のないメインビジュアル・空のキャッチコピー・空の会社名）は、取り込んだページの一部を隠す・空にすることで表し、
  作る操作に合わせて元に戻しています（`js/scenario.js` の `homeEmpty` / `noLogo` / `heroNoImg` / `heroCopyEmpty` / `ovNameEmpty`）。
  ミスの状態（`heroBoxed`：背景を 980px に縮める、`spHeroBig`：モバイルで文字を大きくする）はスタイルを足して再現しています。
- アップロードでメディアに入る画像は、取り込んだページの画像（ロゴ・本社の写真・製品の写真）です。

## 演出であるもの

- Wix のエディタの画面全体（トップバー・左のツールバー・選択枠と浮かぶツールバー・各パネル・公開のダイアログ）。キャンバスはページを 1920px で描いて、エディタの幅に縮小して表示しています。
- 「サイトのプレビュー」はエディタの枠を消してページを全幅で表示したものです。
- 制作の順序と所要時間（実際の制作は数日〜数週間）。製品・サービスより下のセクションは、同じ手順の繰り返しとして続けて表示しています。

## サイトを更新した場合

```
npm run snapshot -- wix-light-op     サイトの画面・画像・フォントを取り込み直す（tools/snapshot-store.js → 画像は WebP に変換）
npm run timeline -- wix-light-op     長さ・チャプターの測定とサムネイルの撮影
```

取り込むページと取り除く要素は `js/config.js` の `snapshot` で設定します。
Wix のフォントは woff2 / woff / ttf の 3 形式が取り込まれます。ブラウザが使うのは woff2 だけなので、取り込み後に
`assets/site/static.wixstatic.com/ufonts/*/woff` と `*/ttf` のフォルダ（同じフォントの woff2 があるもの）を削除しています（約 110 MB）。

