# 制作プロセス デモ — はらいろ整骨院（harairo.com）・へいわじま整骨院（heiwajima-seikotsuin.com）WordPress 既存ページの修正

> 一覧ページ（`/`）と再生ページ（`/watch/wp-seikotsuin-fixes`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/wp-seikotsuin-fixes/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME）で、長さは 5 分 32 秒です。

画面録画用のデモページです。Windows 11 のデスクトップを模した画面上でマウスカーソルが自動で動き、
2 つの整骨院の WordPress サイトに届いた **修正依頼（2026/10/30）を 1 回の保守作業でまとめて対応する工程** を順番に再生します。

**依頼の確認 → 施術メニュー・予約リンクの追加（HTML・CSS）→ フッターの表記・検索結果の説明文 → 診療時間の修正 → スマホ表示の調整 → 公開サイトの確認**

## 録画の手順

1. `public/videos/wp-seikotsuin-fixes/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/wp-seikotsuin-fixes/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（サイトの画面・画像・フォントと管理画面の先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「2 つの整骨院サイトの修正依頼 6 件が完了」と出たら録画を停止

### 日本語入力（Microsoft IME と同じ流れ）

メニュー名（酸素カプセル）・フッターの表記（祝日は要問い合わせ）・診療時間（時は予約制）・All in One SEO の説明文は、ローマ字を 1 キーずつ入力 → 変換 → 確定 の流れで入力しています。
英数字は IME をオフにして入力し、画面下に押したキーを表示します。

## キー操作 / URL パラメータ

ほかのデモと同じです（`../../README.md`）。**Space** 再生 / 一時停止、**R** 最初から、**C** 字幕、**H** ヒント、`?t=秒` `?from=シーン番号` `?speed=1.3` `?captions=0`。

## 本番サイトとの同一性について

- ブラウザに表示される 2 つのサイトは、公開中のページをブラウザで開き、サイトのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/site-snapshot.js`・`assets/site/`）。
  スタイルシートは本番のファイルのまま、画像はその幅で表示されていたサイズのものです。スクリプトは取り込んでいません。
- 修正前・ミスの状態は、取り込んだ画面に `js/apps.js` の状態（`StoreFrame.STATES`）をかけて再現しています：
  `h10`（メニュー 10 を隠す）、`hCta`（予約案内のリンクを隠す）、`hIcon`（アイコンを壊れた画像に）、`hNote`（フッターを「土曜17:00まで」に）、
  `hNoSp`（スタイルシートからリンクのタブレット・スマホ用ルールを外す）、`wHours`（旧診療時間）、`wAddr`（住所の改行なし）、`wTypo`（`br-sp` の改行）。
  はらいろの右側のタブ（`#fixbtn`）は、サイトのスクリプトと同じくスクロール後は固定表示、タイトルのクリックで開閉します（`hSide`）。
- VS Code で編集した `front-page.php`・`footer.php`・`base.css` の最終形は、公開ページのマークアップ・本番の `base.css` と一致することを再生のたびに確かめています（`npm run verify` が文字の違いを報告します）。
- WordPress の管理画面は本物の画面の取り込みです（`js/wp-snapshot.js`）。管理画面の時刻・日付（2026/10/30 14:31 ごろ）は動画の時計に合わせています。
  All in One SEO のプレビューに表示されるアドレスは harairo.com に置き換えています。

## 演出であるもの

- **画面の環境**：VS Code は今の既定の見た目（Dark Modern）、PHP の色分けは VS Code と同じです。タブのファビコンは両サイトの本物です。
- ターミナルの `scp` の出力（転送量・速度）は、実際のコマンドの出力の形式に合わせた表示です。サーバー側のパスと SSH の接続名（`harairo`・`heiwajima`）は再現です。
- 作業の途中で時計を進めています（14:06 → 14:58）。

## サイトを更新した場合

```
npm run snapshot -- wp-seikotsuin-fixes       2 つのサイトの画面・画像・スタイルシート・地図を取り込み直す
                                               （tools/snapshots/wp-seikotsuin-fixes/update-snapshot.js → capture-maps.js、画像は WebP に変換）
node tools/snapshots/wp-seikotsuin-fixes/capture-wp.js    WordPress の管理画面を取り込み直す（WordPress Playground・ログインは使い捨ての環境のみ）
npm run webp -- wp-seikotsuin-fixes
```

取り込み・地図の撮影は公開ページだけを開き、ログインはしません。
