# 制作プロセス デモ — 仁秀 NINSHU（ninshu.com）WooCommerce による EC サイト構築

> 一覧ページ（`/`）と再生ページ（`/watch/wp-ninshu-woocommerce`）から、シークバー付きのプレーヤーで見られます（`npm run dev` で起動）。詳しくは `../../README.md`。
> 動画のページ本体は `public/videos/wp-ninshu-woocommerce/`（`index.html` はブラウザで直接開いても再生できます）。
> 画面は Windows 11（タスクバー・ポインター・IME）で、長さは 9 分 5 秒です。

画面録画用のデモページです。Windows 11 のデスクトップを模した画面上でマウスカーソルが自動で動き、
京焼・清水焼の窯元 仁秀 NINSHU のオンラインショップ（https://ninshu.com/）を **WordPress ＋ WooCommerce で構築する工程** を順番に再生します。

**WooCommerce の導入・ストア設定 → 配送方法・送料 → オンライン決済 → 会員登録・ログイン → 商品登録（CSV インポート）→ 注文管理 → 公開中のショップで確認**

## 最初に確認していただきたいこと

- ninshu.com は **WordPress ＋ WooCommerce で運営されている実在のショップ** です（公開サイトのプラグイン：WooCommerce・Product Add-ons・WPML・EWWW Image Optimizer、テーマ：TCD の有料テーマ「EGO」（フォルダー `ego_woocommerce_tcd079`））。
  このデモは「WooCommerce でこのショップを作る」としたらどう進めるか、という **工程の再現** で、実際の構築作業の記録ではありません。
- **本物のもの**
  - WordPress / WooCommerce の管理画面は、すべて **本物の WordPress（WordPress Playground）で実際に操作した画面** です（下の「WordPress の画面について」）。
    CSV のアップロードと列の割り当て・インポート、配送ゾーンの作成と地域の選択・配送方法の追加（「配送方法を作成」のダイアログ）、銀行振込の口座の登録、会員の設定、
    バリエーションの価格の入力、注文ステータスの変更（キーを誤ったときに「支払い待ち」になるところを含む）は、その WordPress で実際に行った結果です。
  - ショップのデータ：商品名・SKU・価格（単品 / ペア）・カテゴリー（スラッグも公開サイトと同じ `fc` `kj` など）・商品の説明（抜粋）・商品画像は、
    公開中のショップの Store API（`/wp-json/wc/store/v1/products`）から取得したものです（158 商品・うち単品 / ペアのバリエーションのある商品 26）。
  - ショップの決まり：送料の表（1,300 / 1,400 / 1,500 / 1,600 / 2,100 円の 5 区分・税込 2 万円以上で無料）、決済（クレジットカード・Alipay と銀行振込）、
    会員（ログインは「マイアカウント」）、店舗の住所、振込先の口座は、公開サイトのご利用ガイド・特定商取引法の表示のページの内容です（口座番号は画面でぼかしています）。
  - ブラウザに表示される公開中のショップの画面（トップ・商品ページ・カート・マイアカウント）と、サイトアイコン（ファビコン）。
- **再現のもの**
  - 開発環境（wp-env）・プロジェクトのファイル（構築メモ `docs/requirements.md`、商品 CSV、ショップのプラグイン `ninshu-shop`）・ターミナルの出力は、説明のために作ったものです。
    CSV は WooCommerce の CSV インポートの形式に、公開サイトの商品データを入れたものです。
  - **テーマは使っていません**：公開サイトのテーマ TCD「EGO」は有料のため、取り込みに使った WordPress には入れていません（既定のテーマ Twenty Twenty-Five）。
    **テーマのオプション画面（TCD のテーマオプションなど）は動画に出てきません。** VS Code のファイル一覧に `wp-content/themes/ego_woocommerce_tcd079` のフォルダーを閉じた状態で表示しているだけです。
  - Stripe は **ショップ自身の Stripe アカウントで接続する** 必要があるため、動画では Stripe プラグインの本物の設定画面（「Stripe を始める」）を表示するところまでです。
    API キー（本番・テストとも）は入力も表示もしていません。
  - テスト注文 3 件の購入者（山本 美咲・中村 大輔・佐藤 陽子、`@example.jp` のメールアドレス・住所）は架空のもので、画面ではぼかしています。
  - 3 つのミス（ペアの価格の入れ忘れ・北海道・沖縄の送料無料の追加漏れ・注文ステータスのキーの誤り）は演出です（画面はどれも実際にその状態にした WordPress のものです）。
- このカテゴリーの参考として挙げられていた www.nova-organic.co.jp（WooCommerce のショップ）は、この動画には登場しません（画面は ninshu.com だけです）。
- 仁秀は実在の事業者です。このデモはローカルのファイルとしてだけ使ってください（Web に公開しないでください）。

## 録画の手順

1. `public/videos/wp-ninshu-woocommerce/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/wp-ninshu-woocommerce/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（ショップの画面・WordPress の画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「商品登録・送料・決済・会員・注文管理まで、WooCommerce でショップが動く」と出たら録画を停止

## 本番サイトとの同一性について

- 公開中のショップの画面（トップページ・商品ページ「禅｜ぜん｜フリーカップ」・カート・マイアカウント、PC 幅 1920px、トップページはスマートフォン幅 390px も）は、ninshu.com をブラウザで開き、
  サイトのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/site-snapshot.js`・`assets/site/`）。スタイルシートは本番のファイルのまま、画像はその幅で表示されていたサイズのものです。
  スクリプト・Cookie の通知・reCAPTCHA は取り込んでいません。公開サイトが読み込んでいるスタイルシートのうち 1 つ（Instagram Feed の `sb-tokens-local.css`）はサーバーに無く、
  WordPress の HTML ページが返ってくるため、取り込んだ後に空にしています（`tools/snapshots/wp-ninshu-woocommerce/fix-site-css.js`）。カートは「月雲の大皿」を 1 点入れた状態（`/cart/?add-to-cart=494`）を取り込んだものです。
- 商品ページで「ペア」を選んだ状態は、ページに埋め込まれているバリエーションのデータ（`data-product_variations` の価格の HTML）を WooCommerce のスクリプトと同じ場所に表示して再現しています（`js/apps.js` の `pairChosen`）。
- 管理画面に並ぶ商品（名前・SKU・価格・カテゴリー・画像）は公開中のショップの商品データです。商品の本文（長い説明）・在庫数・Product Add-ons のオプション（桐箱・名入れなど）・WPML の英語ページは取り込んでいません。

## WordPress の画面について

- 管理画面は、**WordPress Playground**（ブラウザの中で動く本物の WordPress。WordPress 7.1.4 / PHP 8.3）に wordpress.org の WooCommerce 11.3.0 と WooCommerce Stripe Gateway 11.2.0、
  それぞれの日本語の翻訳を入れ、上の CSV・設定・プラグインで実際に操作した画面を取り込んだものです（`tools/snapshots/wp-ninshu-woocommerce/capture-wp.js` → `js/wp-snapshot.js`・`assets/wp/`）。
- ログインはしていません（Playground の使い捨ての管理者で操作しています）。アドレスバーのアドレスは開発環境の `http://localhost:8888/…` に置き換えています。
- 商品の取り込みは、WooCommerce 自身の CSV インポーター（`WC_Product_CSV_Importer`）を、画面の列の割り当てのまま 12 行ずつ実行しています（Playground では画面の AJAX のくり返しが非常に遅いため。結果の「完了しました」の画面と件数は本物です）。
  取り込み後、カテゴリーのスラッグを公開サイトと同じもの（`fc` `kj` `oc` など）にしています。
- 地域の選択は、1 件目（富山県）を選ぶところまでを動画で見せ、残りの 21 府県を選んだ後の画面に切り替えています（どちらも実際に選んだ状態の画面です）。
- 1 つ目のゾーン（関西・中部・中国・四国）は画面で作成・保存しています。残りの 4 ゾーン（関東・甲信越・九州 / 南東北 / 北東北 / 北海道・沖縄）は、同じ設定を WooCommerce の関数で作っています（動画では「同じように作成」として一覧から見せています）。
  北海道・沖縄 の送料無料は、動画と同じく画面の「配送方法を追加」から追加しています。
- テスト注文は WooCommerce の関数（`wc_create_order`）で作り、注文の編集画面のステータスの変更・「更新」は画面で実際に行っています。
  キーを `shipped` にしたプラグインで「発送済み」を選んで更新すると、WooCommerce が知らないステータスとして扱い「支払い待ち」になります（取り込んだ画面はその結果です）。
- 開いた状態の地域の一覧・注文ステータスの一覧（select2）は、ボックスにフォーカスがある間だけ開いているため、取り込む間だけフォーカスを外さないようにしています。
  「ゾーンを追加」を開いた直後の画面は、取り込みの仕組みで一瞬フォーカスが地域の欄に入り一覧が開いた状態で保存されたため、表示するときに一覧とタグ（どこにでも）を閉じた状態に戻しています（`js/scenario.js`）。
- 注文の購入者の氏名・住所・メールアドレス・電話番号、振込先の口座番号は、画面でぼかしています。
- WooCommerce の案内・宣伝の通知（WooPayments の案内など）は、運用中のショップと同じく「非表示にした」状態で取り込んでいます。
- 画面の日付は動画の日付（2026 年 11 月 4 日）に、取り込んだときの「今」の時刻（商品の取り込み・更新、注文メモ）はタスクバーの時計（その画面が出る 10:10 / 10:12）に合わせています。
  注文一覧の日付は、WooCommerce がその時刻に表示するとおり「46分前」「2時間前」…にしています（`tools/snapshots/wp-ninshu-woocommerce/fix-wp-snapshot.js`）。
- 決済の一覧の矢印のアイコン（WooCommerce の gridicons。SVG のスプライトで、取り込みでは保存されない）は、同じアイコンの形をその場に描いています（同じファイル）。

## 演出であるもの

- 管理画面のネイティブのセレクトボックス（送料無料の必要条件・商品のカテゴリーの絞り込み）を開いたときの一覧は、Chrome の一覧に似せて描いたものです（選んだ後の画面は本物）。

## 画面の環境

- VS Code は今の既定の見た目です（Dark Modern テーマ、VS Code 自身のアイコン codicon、Seti のファイルアイコン、ミニマップ。`public/shared/vscode.css` / `vscode.js`）。ターミナルは PowerShell です。
  プラグインの PHP はインデントを WordPress のコーディング規約どおりタブにしています。
- タブのアイコンは、管理画面がショップの WordPress のサイトアイコン（公開サイトと同じ画像）、公開中のショップがサイトのファビコンです。
- タスクバーの日付は 2026/11/04 で、画面の時刻はタスクバーの時計に合わせています。

## サイトを更新した場合

```
npm run snapshot -- wp-ninshu-woocommerce                    公開中のショップの画面・画像を取り込み直す
node tools/snapshots/wp-ninshu-woocommerce/fix-site-css.js   CSS の代わりに HTML が返ってきたスタイルシートを空にする（取り込み直したら毎回）
node tools/snapshots/wp-ninshu-woocommerce/capture-wp.js     WordPress の画面を取り込み直す（Playground、約 15 分。最後に fix-wp-snapshot.js も実行）
node tools/webp.js wp-ninshu-woocommerce                     WordPress の画面の画像を WebP に
npm run timeline -- wp-ninshu-woocommerce                    長さ・チャプターの測定とサムネイルの撮影
```

取り込むショップのページ（トップ・商品・カート・マイアカウント）と取り除く要素は `js/config.js` の `snapshot` で設定します。
