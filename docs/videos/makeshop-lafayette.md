## 最初に確認していただきたいこと

- www.lafayettecrew.jp は **makeshop で運営されている実在のショップ** です（画像・CSS は gigaplus.makeshop.jp / makeshop-multi-images.akamaized.net の `lafayette`）。
  このデモはその構築・カスタマイズの工程の **再現** で、実際の作業の録画ではありません。
- 在庫は makeshop の管理画面で SKU ごとに入力・表示する範囲を扱っています（外部のシステムとの在庫の自動同期などは扱っていません）。
- **ショップの実データ**：
  - 「ブランドから探す」「アイテムから探す」のカテゴリーと URL、LFYT の子カテゴリーと件数（LFYT 2026 Autumn/Winter Collection (33)・LFYT クルースウェット/パーカー (21) など）、一覧の件数表示（全 221 件中 48 件表示 など）と並び順の選択肢

  - Lafayette LOGO QUILTED HOODIE（LA260502・¥22,000）の「販売期間外の商品です／2026年11月21日11：00より販売開始」
  - 会員特典（ご購入額の 1%・新規登録 500 ポイント・5 段階の会員ランクで最大 10%）、お支払い方法（クレジットカード・クロネコ代金後払い・楽天ペイ・LINE Pay・Paidy・キャリア決済・Amazon Pay）、
    送料（600〜1,100 円・ヤマト運輸）と 11,000 円以上の送料無料、店舗受け取り、予約商品を含む注文で LINE Pay が使えないこと（ご利用ガイド・お支払い方法・会員特典のページ）
  - ブラウザに表示されるショップの画面（トップ・LFYT のブランドページ・新着から探す・「HOODIE」の検索結果・2 つの商品ページ、PC 幅 1920px / スマートフォン幅 390px）
- **makeshop の画面**：ログイン画面（https://console.makeshop.jp/login）は本物をそのまま取り込んだものです。ログイン後の管理画面はアカウントが必要なため再現ですが、
  ロゴ・アイコン・色・ページのタイトルの形式（「〇〇 - makeshop byGMO」）は管理画面自身の公開 JavaScript から取った本物です（下の「makeshop の画面について」）。

  SKU コード（`LA260501-BK-S` など）と在庫数・再入荷通知の申込数、会員ランク 2〜4 の名前と還元率（公開されているのは 5 段階・最大 10% まで）、ホームの件数、作業の一覧。
- 実在のショップのため、カート・会員登録・ログイン・お気に入り・再入荷通知の申込は **一切操作していません**（取り込んだのは公開ページの表示だけ。商品ページのボタンはポインターを乗せるだけです）。
- 2026/11/13・11/19 付けのお知らせ（動画の日付より後）は、取り込むときにお知らせ一覧から外しています（`js/config.js` の `snapshot.remove`）。
  それ以外の内容（トップのスライダー・新作の告知・新着の商品など）は取り込んだときのままです。
- Lafayette は実在の企業のショップです。このデモはローカルのファイルとしてだけ使ってください（Web に公開しないでください）。

## 録画の手順

1. `public/videos/makeshop-lafayette/index.html` を **Google Chrome** で開く（ダブルクリックで可。サーバーは不要。`npm run dev` 中なら http://localhost:3000/videos/makeshop-lafayette/index.html でも可）
   - 準備に 5〜20 秒ほどかかります（ショップの画面・画像・フォントの先読み）。タイトル画面が出たら準備完了です
2. **F11** で全画面表示にする（推奨：1920×1080、ブラウザのズーム 100%）
3. 画面録画を開始する
4. **Space** キーで再生開始
5. 最後に「makeshop でのアパレル EC サイトの構築・カスタマイズが完了」と出たら録画を停止

### 日本語入力（Microsoft IME と同じ流れ）

カテゴリー名の「クルースウェット」「パーカー」は、ローマ字を 1 キーずつ入力 → 変換 → 確定 の流れで入力しています。
英数字（品番・価格・URL・カラー・サイズ・時刻など）は IME をオフ（半角/全角）にして入力し、画面下に押したキーを表示します。

ほかのデモと同じです（`../../README.md`）。**Space** 再生 / 一時停止、**R** 最初から、**C** 字幕、**H** ヒント、`?t=秒` `?from=シーン番号` `?speed=1.3` `?captions=0`。

## 本番サイトとの同一性について

- ブラウザに表示されるショップは、公開中のショップをブラウザで開き、ショップのスクリプトが動いた後の画面を **そのまま取り込んだもの** です（`js/site-snapshot.js`・`assets/site/`。画像は WebP に変換）。
  スクリプト（計測タグ・チャット・決済ボタン）は取り込んでいません。
- ミスの状態は、取り込んだ画面を一時的に書き換えて再現しています（`js/scenario.js`）：
  `noStock`（在庫 0 の SKU の「再入荷通知を受け取る」を「カートにいれる」に）、`cheapFirst`（新着の一覧を価格の低い順に並べ替え）、`release0100`（販売開始の時刻を 01：00 に）。修正後は取り込んだままの画面です。
- 管理画面のカテゴリー・子カテゴリーの件数・商品名・価格は、ショップの公開ページから取得したものです（`tools/snapshots/makeshop-lafayette/build-files.js`）。

## 演出であるもの

- VS Code は今の既定の見た目です。`docs/shop-rules.md` は、ショップのご利用ガイド・会員特典・お支払い方法のページの内容をまとめたもので、このデモのために作ったファイルです。
- 管理画面の処理の進み具合・トースト・件数の表示は演出です。管理画面のカテゴリーは、すでにショップにあるものを「追加する」操作として見せています。

## サイトを更新した場合

```
npm run snapshot -- makeshop-lafayette                 ショップの画面・画像を取り込み直す（tools/snapshot-store.js → 画像は WebP に変換）
node tools/snapshots/makeshop-lafayette/build-files.js  カテゴリー・件数・商品から js/files.js を作り直す
npm run timeline -- makeshop-lafayette                  長さ・チャプターの測定とサムネイルの撮影
```

取り込むページ・取り除く要素は `js/config.js` の `snapshot` で設定します。在庫の状態（売り切れの SKU）は取り込んだときのものなので、取り込み直したら `js/apps.js` の `STOCK` と字幕を合わせてください。

## makeshop の画面について（本物のものと、再現のもの）

- **ログイン画面は本物です**：https://console.makeshop.jp/login を取り込んだもの（`js/makeshop-login.js`・`assets/makeshop/login/`）で、ほかの makeshop の動画と同じファイルです。ログインは送信していません。
- **ログイン後の管理画面は再現です**（アカウントが必要なため）。横長のロゴ・アイコン・テーマの色・タイトルの形式は、管理画面自身の公開 JavaScript から取ったものです（`js/makeshop-ui.js`）。
  メニューの大項目とグループの見出しは管理画面と同じですが、サブメニューの名前と各ページのフォーム・配置は再現です。
- 取り込み直し：`node tools/snapshots/tabisuruwagashi/capture-makeshop.js`（旅わが・日清食品グループの動画のフォルダに書き出します。このデモへは `js/makeshop-*.js` と `assets/makeshop/` をコピー）。

## ファイル構成

```
index.html            ページ本体（共通の部品は public/shared/kit/ と public/shared/）
css/video.css         このデモだけの見た目（makeshop の管理画面）

js/site-snapshot.js   取り込んだショップの画面（自動生成）
js/files.js           カテゴリー・件数・商品と、VS Code に表示するファイル（自動生成：tools/snapshots/makeshop-lafayette/build-files.js）
js/apps.js            makeshop の管理画面（再現）の各ページ
js/makeshop-login.js  makeshop の本物のログイン画面（自動生成）
js/makeshop-ui.js     makeshop 管理画面の公開 JavaScript から取ったアイコン・色・タイトルの形式（自動生成）
js/makeshop-login-frame.js  ログイン画面の表示と入力
js/scenario.js        台本（シーンごとの操作・字幕・ミスと修正）
assets/site/          取り込んだ画像・フォント（自動生成）
assets/makeshop/      makeshop のログイン画面の画像・管理画面のロゴ（自動生成）
```
