# こしば日和（shiba-ikusei）

柴犬の子犬を、現実の時間に合わせて育てる育成ゲーム。犬はすべてコード（canvas）で描かれ、画像がなくても動き、表情を変え、眠り、ごはんを食べます。

- 遊ぶ: `/games/shiba-ikusei/`
- ファイル: `public/games/shiba-ikusei/`（`index.html`・`dog.js`・`game.js`・`style.css`・`icon.svg`・`images.json`）

## 概要

| 項目 | 内容 |
| --- | --- |
| ジャンル | 育成（ペット）・ミニゲーム |
| 時間 | 現実の時計で進みます（ふつう：現実の 1 日で 3 日ぶん／はやい：1 時間で 1 日／デモ：3 分で 1 日） |
| 成長 | 子犬（0〜4 日）→ 若犬（5〜13 日）→ 成犬（14 日〜）。見た目・体の大きさ・しぐさ・教えられる技が変わります |
| ステータス | おなか・ごきげん・清潔・体力・なつき度（ほかに体重・遊び・しつけ・なでた回数などの隠し値） |
| 記録 | 日記（自動で書かれる文章）・アルバム（思い出の写真と成長の絵）・きろく（技・ベスト記録）。GK.store に保存 |

## 遊び方（操作）

最初に子犬に名前をつけます（あとで設定から変更可）。下のボタン（PC では部屋の下）でお世話をします。

| お世話 | 内容 |
| --- | --- |
| 🍚 ごはん | ドライフード（いつでも）・ふかしいも・ささみ・特製ごはん。満腹のときは食べません |
| 🍪 おやつ | ごきげんとなつき度が上がります。1 日に 5 個をこえると「あげすぎ」に |
| ✋ なでる | 犬を指・マウスでこすってなでます。頭（目を細めて耳を寝かせる）・あごとほほ（舌を出して首をかしげる）・せなか・おなかで反応が違い、しっぽにさわるとびっくりして跳びあがり、足をタップするとお手（またはおすわり） |
| 🎾 あそぶ | ボールなげ（5 投）。ボールを上へスワイプ（向きと強さ）／タップで投げ、犬が落下点へ走ります。ボールが落ちる直前、赤い輪になった瞬間に「キャッチ！」でジャンプキャッチ（パーフェクト 20 点・ナイス 12 点・おしい 3 点） |
| 🐾 さんぽ | 40 秒の横スクロール。タップ／スペースでジャンプして、水たまり（どろんこ）と石（つまずく）をよけ、ほね（おやつ）と季節の宝もの（春：桜の花びら・夏：四つ葉のクローバー・秋：どんぐり・冬：まつぼっくり）を集めます。お友だちのわんこ・近所のおばあさん・ねこに出会うと、ボタンで答えます（ねこには 1.6 秒以内に「まて！」） |
| 🛁 おふろ | 犬をこすってあわだて（70% 以上）、シャワー → ぶるぶる。なつき度が高いと、おふろが好きになります |
| 🌙 ねる | あかりを消して眠らせると、体力がよく回復します（「おきる」で起こす）。体力が尽きると自分でうたた寝も |
| 🎓 しつけ | 技を選び、縮んでいくわっかが点線の円に重なった瞬間に合図（5 回で 1 回の練習）。経験で ★1〜★3、★3 で「覚えた」。おすわり・お手（子犬）、ふせ・まて（若犬）、おかわり・くるりん（成犬） |

キーボード: `1`〜`8` お世話のボタン、`Space`（`Enter`・`↑`）ミニゲームの操作、`Esc` メニュー。

ほかに、ショップ（ポイントでごはん・おやつ・家具）、日記、アルバム、きろく、設定（名前・時間の速さ・やり直し）。

## システム

- **時間**: ゲーム内の時間は「現実の経過時間 × 速さ」。おなか・ごきげん・清潔は時間とともに下がり、体力は起きている間は少しずつ下がって、眠ると回復します（ベッドがあると早く、あかりを消すとさらに早く）。
- **留守のあいだ**: ページを閉じていた時間も成長は進みますが、ステータスの変化は半日ぶん（ゲーム内 18 時間）までに抑えます。犬は弱ったりいなくなったりせず、いちばん悪くても「すねる」だけ（そっぽを向き、遊び・しつけ・さんぽを断る）。なでる・おやつ・ごはんで機嫌がなおります。3 時間以上あけて開くと「おかえり！」と迎えてくれ、日記にも残ります。
- **昼・夕方・夜と季節**: 現実の時計で部屋の背景（昼 5〜16 時・夕方 16〜19 時・夜）が切り替わり、季節（月）でさんぽの景色の色・降るもの（花びら・落ち葉・雪）・見つかる宝もの・「季節のかざり」（桜の枝・風鈴・紅葉の枝・雪うさぎ）が変わります。夜は眠くなる音楽に。かべ時計は現実の時刻を指します。
- **成長と性格**: 成長段階で体の比率（頭の大きさ・足の長さ・体格）と鳴き声の高さが変わります。おとなになると、育て方（遊び・しつけ・なでる）で性格が決まり、部屋でのしぐさが変わります（元気いっぱい：部屋を走りまわる／かしこい：覚えた技をひとりで披露／あまえんぼう／のんびりや：よく寝そべる）。
- **ポイント**: ボールあそび・さんぽ・しつけ・おふろ、毎日のログイン（1 日 +20pt）でもらえ、ショップで使います。家具（ラグ・かべ時計・観葉植物・おもちゃ箱・ふかふかベッド・季節のかざり）は部屋に置かれ、効果もあります。
- **日記とアルバム**: はじめてのごはん・さんぽ・おふろ、技を覚えた日、成長した日、すねた日、留守のあとなど、出来事に合わせて自然な文章の日記が書かれます。節目では、部屋のその瞬間の canvas を切り抜いた「思い出の写真」がアルバムに残ります（最大 30 枚）。成長の絵（各段階の肖像）も並びます。
- **音**: BGM は 4 曲の書きおろし（昼のテーマ・夜の子守歌・さんぽのマーチ・ミニゲーム）。鳴き声（成長で高さが変わる）・食べる音・あわ・シャワーなどは WebAudio で合成。

## 独自の要素（既存作品との違い）

- 卵型の携帯ゲーム機のような見た目ではなく、**明るい部屋に犬がいる、絵本のような 1 画面**。犬は画像ではなくコードで描いているので、まばたき・しっぽ・耳・首かしげ・ジャンプ・食べる・寝息まで、すべてなめらかに動きます。
- **なでる場所で反応が変わる**「なでる」操作と、しっぽにさわるとびっくりするといった柴犬らしいしぐさ。
- **季節と時刻が現実と連動**し、さんぽで見つかる宝もの・部屋のかざりが季節で変わります。
- **死なない・弱らない**やさしい設計（最悪でも「すねる」）と、留守の変化の上限。
- 日記の文章とアルバムの写真が自動で積み重なり、育てた日々が「記録」として残ります。

## 画像

14 枚（キービジュアル・部屋の背景 3 枚（昼・夕方・夜）・さんぽの遠景・柴犬の肖像 9 枚（3 段階 × ふつう・ごきげん・しょんぼり））。いまは画像サンプルで、犬そのものはコードで描いているため、サンプルのままでも遊べます。肖像はステータス欄とアルバムに使います。生成用のプロンプトは [prompts/shiba-ikusei.md](prompts/shiba-ikusei.md)。

| 種類 | ツール | そろえ方 |
| --- | --- | --- |
| 部屋の背景 3 枚 | Midjourney（v7） | 昼の絵を `--sref` にして、同じ構図の夕方・夜を作る |
| さんぽの遠景 | Stable Diffusion XL | 「Tiling」で左右がつながる横長の絵に |
| 肖像 9 枚 | ChatGPT（透過 PNG） | 子犬・ふつうを基準に、完成画像を添付して表情と年齢だけを変える |
| キービジュアル | niji・journey | 肖像（子犬）を `--cref` にして同じ犬に |

## 技術メモ

- `dog.js`: 柴犬の描画（おすわり・ふせ／寝る・横向き（歩く・走る））。3 段階の体の比率、目（ふつう・笑顔・閉じ・驚き・しょんぼり・半目）、口（ω・開く・舌・もぐもぐ・への字）、耳の角度、首かしげ、お手の前足、ボールをくわえる、ほかの犬の毛色（さんぽの出会い）。麻呂眉・裏白・巻き尾など柴犬の特徴を形にしています。
- `game.js`: 時間（ゲーム内の分 = 現実の経過 × 速さ、留守の上限）、部屋の AI（歩く・寝そべる・においをかぐ・技の披露・要求の吹き出し）、なでる場所の当たり判定、4 つのミニゲーム（ボール・さんぽ・しつけ・おふろ）、ショップ・日記・アルバム・きろく・設定。部屋は奥行きのある床（奥ほど小さく）に犬と家具を描いています。
- レイアウト: スマホ縦（上にステータス、真ん中に部屋、下に 4×2 のお世話ボタン）、PC（左にステータスと肖像、中央に部屋、右にポイント・日記）、横長スマホ（左にステータス、右に 2 列のボタン）。
- 自動テスト（`window.__gameSelfTest`）: 名前をつけてはじめる → ごはん → 頭をポインター操作でなでる → ボールあそび（投げてキャッチ）→ さんぽ（ジャンプ・出会い）→ しつけ（タイミングを合わせて合図）→ おふろ → デバッグ用の `window.__shiba.advanceDays()` で若犬・成犬に育ててアルバムを確認 → 家具を置いた部屋・夜（消灯）・アルバム・ショップ。終わったら保存データを元に戻します。
