# みやび札 ― 百人一首かるた（`hyakunin-isshu`）

`public/games/hyakunin-isshu/` ・ 遊ぶ: `/games/hyakunin-isshu/`

## 概要

小倉百人一首の 100 首で遊ぶかるたです。読手が上の句を一音ずつ読み上げ、その歌の下の句が書かれた取り札を早く取ります。

- **対戦** ― CPU と競技かるた風に。自陣・敵陣・空札・送り札・お手つきのある本格的なルールで、相手は 4 人（強さが違う）。
- **ちらし取り** ― ひとりでタイムアタック（10・20・30 枚）。
- **決まり字練習** ― 決まり字または上の句を見て、取り札を 4 枚から選ぶ。まちがえた歌ほどよく出る間隔反復。
- **百首一覧** ― 100 首を歌・歌人・読み・番号で検索。決まり字の字数で絞り込み、取り札の見た目と読み上げも確認できます。

## 遊び方（操作）

| 操作 | PC | スマホ |
| --- | --- | --- |
| 札を取る | 札をクリック（押した瞬間に判定） | 札をタップ（触れた瞬間に判定） |
| 送り札を選ぶ | 光っている自陣の札をクリック（9 秒で自動） | タップ |
| 練習の答え | 札をクリック / <kbd>1</kbd>〜<kbd>4</kbd> キー、<kbd>Enter</kbd> で次へ | タップ |
| 中断・やり直し・タイトルへ | 右上の ≡ | 同じ |
| 声の読み上げ | 対戦画面右下の「声」、またはタイトルの「読み上げの設定」 | 同じ |

読み上げは、上の句が一音ずつ文字で現れます（速さは ゆっくり / ふつう / はやい）。端末に日本語の音声（Web Speech API の `speechSynthesis`、端末内の音声のみ）があれば、声でも読み上げます。取られた後は下の句を表示し（声ありなら下の句も読み上げ）、次の歌へ進みます。対戦の最初には序歌「難波津に」を読みます。

## ルール

### 対戦（競技かるた風）

- 100 枚から各陣に同じ枚数を配ります。**各陣 25 枚（本式）**。画面が小さいとき（幅 900px 未満 または 高さ 600px 未満）は 15 枚までにし、スマホ縦の既定は **12 枚**（8 枚も選べます）。
- 札は各陣 3 段に、左右の端から並べます（真ん中が空く本式の並べ方）。**横長のスマホ（高さ 520px 未満）は 2 段**にして、読み上げの欄を左に置きます。
- 読む歌は「場にある札」と、同じ数の「空札（場にない歌）」を混ぜた順です（各陣 25 枚なら 100 首すべて）。
- 読まれた歌の取り札に先に触れた方が取ります。**敵陣の札を取ったら、自陣の札を 1 枚選んで相手に送ります**（送り札）。
- **お手つき** ― 空札のときに札に触れた / 読まれた札がない方の陣の札に触れた。相手から 1 枚送られてきます。読まれた札と**同じ陣**の別の札に触れたときはお手つきになりません（競技かるたの規則どおり）。お手つきのあとでも、正しい札を取ることはできます。
- 相手（CPU）がお手つきをしたら、あなたが 1 枚選んで送ります。
- **自陣の札が先になくなった方の勝ち**です。

### CPU の強さ

| 相手 | 歌が分かるタイミング | 反応（秒） | お手つきの率 |
| --- | --- | --- | --- |
| ★ 小春 | 初句（5 音目）か決まり字の遅い方 | 0.7〜1.3 | 10% |
| ★★ 文月 | 決まり字（100 首での決まり字） | 0.55〜0.95 | 7% |
| ★★★ 宵 | 読まれた歌を除いた「変化した決まり字」 | 0.38〜0.6 | 5% |
| ★★★★ 白峰 | 同上 | 0.2〜0.36 | 2.5% |

CPU のお手つきは「出だしが同じ別の札に、区別がつく一音手前で飛びつく」形で起こります（例: 「あさぼらけ」まで聞いて別の「あさぼらけ」の札に触れる）。

### ちらし取り

並べた札だけが読まれます（空札なし）。札が減るほど決まり字が短くなるのが練習になります。全部取るまでの時間 ＋ お手つき 1 回 2 秒 が記録です。読み終わって 4 秒たっても取れないときは、正解の札が光ります。

### 決まり字練習

1 回 10 問。決まり字（例: 「うか…」）か上の句を見て、取り札を 4 枚から選びます。まちがいの選択肢は、なるべく同じ音で始まる歌から選びます。各歌は 0〜5 の「箱」を持ち、正解で 1 つ上がり、不正解で 0 に戻ります。次に出るまでの間隔は箱ごとに 1・3・7・15・30・60 問。箱 3 以上を「覚えた歌」と数えます。範囲は すべて / 1字 / 2字 / 3字 / 4字以上 / 苦手（箱 1 以下）。

### 記録（`GK.store`、`game:hyakunin-isshu:` の下）

`vs`（相手ごとの勝敗と最大枚差）・`chirashi`（枚数ごとの最速）・`srs` / `srsT`（練習の箱と出題カウンター）・`streak`（最高連続正解）・`settings`。タイトルの「読み上げの設定」→「記録を消す」で消せます。

## 独自の要素（既存作品との違い）

- 名前「みやび札」、4 人の対戦相手（小春・文月・宵・白峰）、読手はすべてオリジナル。既存のかるた漫画・アニメ・ゲームの人物や見た目（袴姿の女子高生の主人公など）は使っていません。
- 取り札はコードで描画（生成りに緑の縁、ひらがなの下の句を縦書き 3 行。`writing-mode: vertical-rl`）。濁点は読みやすさのために付けています（伝統的な取り札は濁点なし）。
- CPU が「読まれ終わった歌」を覚えて決まり字の変化を使う、出だしが同じ札に釣られてお手つきをする、という競技かるたらしい強さの差。
- BGM は都節音階（`GK.scales.in`）で新しく作った短い曲（タイトルと一覧のみ。対戦中は読み上げを聞くために無音）。効果音は WebAudio の合成（札を払う音など）。

## 技術メモ

- ファイル: `index.html`・`style.css`・`game.js`（画面・対戦・ちらし・練習・一覧）・`poems.js`（100 首のデータと決まり字の計算。ブラウザでは `window.HYAKU`、Node では `require`）・`test.js`（データの検査）・`icon.svg`・`images.json`。
- **データの出典**（2026 年 11 月に取得して照合）
  - Wikisource「小倉百人一首」 <https://ja.wikisource.org/wiki/小倉百人一首> ― 歌（漢字かな交じり）と歴史的仮名遣いの読み、歌人
  - Wikipedia「百人一首」 <https://ja.wikipedia.org/wiki/百人一首>（「採録された和歌と詠み人達」の表）― 読み・歌人・決まり字の照合
  - 2 つの読みを機械的に比べ、違いのあった歌は次のように決めました: 33「しづごころ」、44「あふことの」、49「夜はもえ」、70「いづこも同じ」（かるたの取り札の表記）、74「山おろしよ」、89「よわりもぞする」。踊り字（ゝ・ゞ）は展開し、旧字体（晝・戀・聲 など）は新字体に。歌人名は一般的な表記に揃えました（柿本人麻呂、山部赤人、猿丸大夫、源宗于朝臣、曽禰好忠、大弐三位、前大僧正行尊、前大僧正慈円 など）。
- **決まり字の計算**（`poems.js` の `kimariji()`）: 上の句の読みを、2 文字目以降のハ行→ワ行・ゐゑを→いえお、語頭の「あふ」は「おう」、「おう」は「おお」（長音）として比べ、他の 99 首と区別できる最短の文字数を求めます（「をぐらやま」と「おくやま」、「あふことの」と「おほえやま」が区別されるのはこのため）。結果は 1字 7（む・す・め・ふ・さ・ほ・せ）・2字 42・3字 37・4字 6・5字 2・6字 6 で、Wikipedia の表の太字（決まり字）と 100 首すべて字数が一致しました。
- **検査**: `node public/games/hyakunin-isshu/test.js` ― 100 首・各句の数・読みがひらがなであること・取り札の重複なし・決まり字の分布（1字7・2字42・3字37・4字6・5字2・6字6）と代表例（ちは / ちぎりき / ちぎりお / あさぼらけあ・う / きみがためは・を / わたのはらや・こ / あふこ / をぐ など）を確認します。`npm run game-check -- hyakunin-isshu` の self-test（`window.__gameSelfTest`）は、対戦で 2 枚取る → 送り札 → 結果画面、ちらし取り 3 枚、練習の正解・不正解、一覧の検索と絞り込みを実際の画面で行います。
- **読み上げの音声**: 表示は歴史的仮名遣い（取り札と同じ）。声には現代の発音に直した読み `t`（例: 「てふ」→「ちょう」、推量の「む」→「ん」）を `SpeechSynthesisUtterance`（`ja-JP`、`localService` の音声だけ）で渡します。声が始まった時点（`onstart`）から文字の表示を始めるので、声と文字がおおむね揃います。音声がない端末では「声も出す」が選べず、文字だけで読みます。
- 盤面は DOM（CSS Grid）。札の移動（送り札）は FLIP アニメーション、取られた札は Web Animations API で飛ばします。判定は `pointerdown`（押した瞬間）。ダイアログを開いている間は試合の時計を止めます。
