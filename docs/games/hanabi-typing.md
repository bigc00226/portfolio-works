# ことば花火 ― 打って打ち上げるタイピング（`hanabi-typing`）

`public/games/hanabi-typing/` ・ 遊ぶ: `/games/hanabi-typing/`

## 概要

夏・祭り・食べ物・旅・季節の言葉をローマ字で打つタイピングゲームです。一文字打つごとに川辺から花火玉が昇り、言葉を打ち終えるとその場所で花火がひらきます。短い言葉は牡丹、長い言葉は菊・柳・千輪と、言葉の長さで花火が変わり、まちがえずに 5 語続けるとスターマインが上がります。制限時間（30・60・90・120 秒）と難しさ（やさしい・ふつう・むずかしい）を選び、結果は「線香花火」から「尺玉」までの 8 つの段位で表します。

## 遊び方（操作）

| 操作 | PC | スマホ・タブレット |
| --- | --- | --- |
| 入力 | 半角英数でローマ字（日本語入力がオンのときは「オフにしてください」と案内） | 画面のローマ字キーボード（次に打つキーが光る） |
| 開始・もう一度 | 「打ち上げ開始」/ <kbd>Enter</kbd>・<kbd>Space</kbd> | ボタンをタップ |
| 一時停止 | <kbd>Esc</kbd> / 右上の ≡ | 右上の ≡ |
| 画面のキーボードの表示 | パネル右下の「キー」で切り替え（タッチの端末は最初から表示） | 同じ |

パネルには、言葉（漢字かな）・読み（打ち終えたかなが金色に）・ローマ字のガイド（打った文字は白、次の文字は金色の枠）が出ます。

## ルール

- **受け付けるつづり**: し shi / si / ci、ち chi / ti、つ tsu / tu、ふ fu / hu、じ ji / zi、しゃ sha / sya、ちゃ cha / tya / cya、じゃ ja / jya / zya、ふぁ fa / fwa、か ka / ca、く ku / cu / qu など。拗音を分けて打つ（ki + xya / lya）、小さい字を l・x で打つ（la・xa・ltu・xtsu）、ー は <kbd>-</kbd>。
- **ん**: nn・xn・n'。次が子音（な行・や行以外）なら n だけでも可。母音・な行・や行の前と言葉の最後は n 一つでは確定しません（一般的な IME と同じ）。
- **っ**: 次の子音を重ねる（kka・cca・tcha など）か、ltu / xtu / ltsu / xtsu。
- **ガイド**は最も一般的なつづりを表示し、打ち始めたつづりに合わせて変わります（例: 「しゃしん」のガイドは shashinn。sy と打つと syashinn に、続けて a・si と打つと syasinn に変わります）。
- **ミス**は文字が進まず、パネルが揺れて花火玉がふらつきます。コンボは途切れます。
- **コンボ**: まちがいなしで言葉を打ち終えると +1。5 の倍数でスターマイン（打ち上げの数はコンボとともに増える）。
- **スコア** = 正しく打った数 × 正確率² × 10 ＋ 最大コンボ × 5。
- **段位**は「1 秒あたりの打鍵数 × 正確率」で決まります: 線香花火（〜1.0）・ねずみ花火（1.0〜）・三号玉（1.6〜）・五号玉（2.2〜）・八重芯菊（2.8〜）・千輪菊（3.5〜）・スターマイン（4.3〜）・尺玉（5.2〜）。
- **記録**（`GK.store`、`game:hanabi-typing:`）: 時間 × 難しさの 12 通りそれぞれのベスト（スコア・段位・打鍵/秒・正確率）。結果画面ではミスの多かったキー（苦手なキー）も表示します。
- **難しさ**は読みの長さで分けています: やさしい ＝ 5 かな以下（179 語）、ふつう ＝ 6〜9 かな（101 語）、むずかしい ＝ 10 かな以上の文（80 文）。合計 360。

## 独自の要素（既存作品との違い）

- 「打つほど花火玉が昇り、打ち終えるとひらく」という見せ方、花火の種類で表す段位、川辺の夏祭りの舞台、花火師見習いのキャラクター「ひばな」はオリジナルです。既存のタイピングゲーム（回転寿司のレーンなど特定の作品の見た目・仕組み）は再現していません。
- 出題の言葉 360 は、このゲームのために作った自然な日本語（季語・祭り・食べ物・旅の言葉と短い文）です。商品名・作品名は入れていません。
- 花火は canvas の粒子で描画（牡丹・菊・柳・千輪・型物の輪・スターマイン、加算合成と残像）。音は WebAudio の合成（打ち上げの笛・ドン・パチパチ）。BGM は陽音階（`GK.scales.yo` と同じ音）と太鼓で新しく作った祭り風の曲。

## 技術メモ

- ファイル: `index.html`・`style.css`・`game.js`（画面・入力・花火・結果）・`romaji.js`（ローマ字判定。ブラウザでは `window.Romaji`、Node では `require`）・`words.js`（出題の言葉）・`test.js`（Node の検査）・`icon.svg`・`images.json`。
- **ローマ字判定**（`romaji.js`）: ひらがな 1〜3 字ごとに「打てるすべてのつづり」の表を持ち、いま打っている塊の候補のうち、打った文字列を接頭辞に持つものが残る限り受け付けます。完全に一致して、より長い候補がなくなった時点で確定。「n」のように確定済みでも次の文字で別の塊が始まりうる場合は、次のキーで判定します（「ん」の n / nn、「っ」の子音の重ね）。ガイドは、打ちかけの塊は打った文字に合う候補を、残りはおすすめのつづりで組み立てます。
- **検査**: `node public/games/hanabi-typing/test.js` ― 631 通りのつづり（shi/si/ci、ti、tu、hu、zi、sya、tya/cya、jya/zya、fa/fwa、xn・n'、っ の重ね・ltu・xtsu、拗音の分け打ち、ー、受け付けてはいけない例 `mikan`・`konnichiha`・`kinyoubi`・`onna` など）と、360 語すべてについて「ガイドどおりに打つと最後まで打てる」「訓令式寄りのつづりでも打てる」「各時点のガイドの次のキーが必ず受け付けられる」ことを確認します。`npm run game-check -- hanabi-typing` の self-test は、実際の入力経路で 3 語打つ（途中で 1 回ミス）→ `syasinn` で「しゃしん」→ 時間切れ → 結果画面 → タイトルを行います。
- 画面のキーボードは `pointerdown` で反応（IME を使わないので変換の問題が起きません）。物理キーボードは `keydown` の `e.key` を使い、`Process`（IME 変換中）のときは案内を出します。
- 花火の描画: 全画面の canvas（`GK.fit` の可変サイズ）に、毎フレーム `destination-out` で少しずつ消してから `lighter`（加算）で粒子を描くので、残像の尾が自然に残ります。粒子は最大 2,600。
