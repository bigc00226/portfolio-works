# ナンプレ帖 ― 9×9 の数字パズル

`public/games/nanpure/` ・ 遊ぶ: `/games/nanpure/`

## 概要

和紙と藍の落ち着いた画面で遊ぶ、ナンプレ（ナンバープレース）です。問題はその場で作り、**答えがひとつだけ**で、ヒント（はじめから入っている数字）は **点対称（180° 回転で同じ形）** に並びます。人が解くときの手順で解いて難しさを測り、**かんたん・ふつう・むずかしい・達人** の 4 段階に分けています。日付で決まる **今日の一問**、解き方を言葉で教える **ヒント**、自動保存と「つづきから」、難易度ごとの記録と **段位** があります。

## ルール

- 9×9 のマスに 1〜9 の数字を入れます。
- どの **行**（横の 9 マス）・**列**（縦の 9 マス）・太線で囲んだ **3×3 のブロック** にも、1〜9 が 1 つずつ入るように埋めると完成です。
- はじめから入っている数字は動かせません。答えはひとつだけです。

## 遊び方（操作）

| 操作 | マウス・タッチ | キーボード |
| --- | --- | --- |
| マスを選ぶ | タップ・クリック | 矢印キー（端で反対側へ回ります） |
| 数字を入れる | 数字ボタン（同じ数字をもう一度押すと消える） | `1`〜`9`（テンキーも可） |
| 消す | 「消す」 | `Backspace`・`Delete`・`0` |
| メモ（候補の小さな数字） | 「メモ」をオンにして数字ボタン | `M` で切り替え、`Shift`＋数字でも書ける |
| 自動メモ | 「自動メモ」 | `A` |
| 戻す・やり直す | 「戻す」「やり直す」 | `Ctrl`＋`Z`・`Ctrl`＋`Y`（`Ctrl`＋`Shift`＋`Z`） |
| ヒント | 「ヒント」 | `H` |
| 一時停止 | 時計の横のボタン | `スペース`・`P` |

- マスを選ばずに数字ボタンを押すと、その数字が盤面のどこにあるかを強調します。
- 選んだマスの行・列・ブロックをうすく色づけし、同じ数字（メモの中の数字も）を山吹色で示します。
- 数字ボタンの小さな数字は「あと何個置けるか」です。9 個置いた数字はうすくなります。
- 正しい数字で行・列・ブロックがそろうと、その並びが光って音が鳴ります。完成すると、最後に入れたマスから波のように盤面が光り、桜の花びらと紙吹雪が舞って結果のカードが出ます。
- 右上のメニューから「最初からやり直す」「別の問題にする」「設定」「タイトルへ」。

### 設定

| 項目 | はじめ | 内容 |
| --- | --- | --- |
| ミスをすぐに知らせる | オン | 答えとちがう数字を赤で表示し、ミスの数を数えます。オフのときはミスを数えず、行・列・ブロックの中で重なった数字だけを赤にします |
| 同じ数字を強調する | オン | 選んだ数字と同じ数字・メモを色で示します |
| メモを自動で消す | オン | 数字を入れたとき、同じ行・列・ブロックのメモからその数字を消します |
| 残りの数を表示 | オン | 数字ボタンに残りの個数を出します |
| BGM を流す | オフ | 陽音階（D の陽旋法）で作った、琴のような静かなオリジナル曲 |

## 難易度と解き方

問題を、人が使う解き方だけで、やさしい手から順に解いてみて、**必要だったいちばん難しい手**で難易度を決めます（数字を当てずっぽうで入れる「仮定」は使いません。どの問題も仮定なしで解けます）。

| 難易度 | 必要な解き方 | ヒントの数 |
| --- | --- | --- |
| かんたん | 隠れたシングル（「この行で 7 が入るのはここだけ」）・唯一の候補 | 36〜37 |
| ふつう | ポインティング（ブロック → 行・列）・クレーミング（行・列 → ブロック）・ネイキッドペア・隠れたペア | 28〜31 |
| むずかしい | ネイキッド / 隠れたトリプル・X-Wing | 24〜31 |
| 達人 | ソードフィッシュ・XY-Wing・XYZ-Wing・クアッド | 24〜32 |

「今日の一問」は曜日で難易度が変わります（月 かんたん・火〜木 ふつう・金〜日 むずかしい）。日付から決まるシードで作るので、同じ日ならだれが開いても同じ問題です。

### ヒント

ヒントは答えをそのまま見せるのではなく、**次に入れられるマスと、その理由**を見せます。

- 例「このブロックで 1 が入れるのは、このマスだけです。」（隠れたシングル）
- 例「このブロックで 4 が入れるのは、1 本の行の上だけです。だから、同じ行のブロックの外のマスには 4 は入りません。その結果、緑のマスに入るのは 6 だけになります。」（ポインティング）

理由に関わるマスは黄色、候補が消えるマスは赤、答えのマスは緑で示し、「数字を入れる」で入れられます。答えとちがう数字が入っているときは、先にその場所を教えます。

### 記録と段位

難易度ごとに、挑戦・クリアの回数、ベスト・平均タイム、ノーミス・ヒントなしのクリア回数を記録します。クリアで点が貯まり（かんたん 1・ふつう 2・むずかしい 4・達人 7・今日の一問 +2）、見習い → 初段 → … → 九段 → 名人 と段位が上がります。途中の問題は数字・メモ・時間ごと自動で保存されます。

## 独自の要素（既存作品との違い）

ナンプレ（数字を入れるパズル）というジャンルは一般的なものですが、問題・画面・名前はすべてこのゲームのためのものです。

- 名前「ナンプレ帖」、和紙と藍の画面、段位の判、結果のカード、BGM はオリジナルです。既存のアプリ・雑誌の問題や見た目は使っていません。
- 問題はすべてこのゲームの生成器で作ります（既存の問題集から取っていません）。
- ヒントが「どの解き方で、なぜそこに入るのか」を日本語で説明します。
- 段位（クリアで貯まる点数）と今日の一問の連続日数で、毎日少しずつ遊べるようにしています。

## 技術メモ

- ファイル: `index.html`・`style.css`・`game.js`（画面）・`sudoku.js`（問題の生成・判定・ヒント。DOM を使わない純粋なモジュールで、ブラウザ・Web Worker・Node で共通）・`worker.js`（生成を別スレッドで）・`bank.js`（作り置きの問題 120 問）・`icon.svg`・`images.json`。
- **答えの数**: ビットマスクのバックトラック（候補がいちばん少ないマスから）で、2 つ目の解が見つかった時点で打ち切ります。
- **生成**: ランダムな完成盤から、点対称の 2 マスずつヒントを外していきます。外したあとも「答えがひとつ」かつ「その難易度までの解き方で解ける」ときだけ外したままにし、最後に「その難易度の解き方が必ず必要」かを確かめます（足りなければ作り直し）。
- **難易度の判定**: 人の手順の解き方（隠れたシングル・唯一の候補 → ポインティング・クレーミング・ペア → トリプル・X-Wing → ソードフィッシュ・XY-Wing・XYZ-Wing・クアッド）を、やさしいものから順に試して解き、使った最も難しい手で決めます。
- **すぐに遊べるように**: 難易度を選ぶと、生成済みの問題（ブラウザに 2 問ずつ作り置き）をすぐに出し、裏の Worker で次の問題を作ります。作り置きがないときは `bank.js` の問題に、盤面の回転・反転と数字の入れ替え（答えの数・難易度・点対称は変わらない）をかけて出します。今日の一問はその日のシードで Worker が作り、その日のうちは保存したものを使います。
- **テスト（Node）**: 難易度ごとに 60 問ずつ（計 240 問）生成し、答えがひとつ・点対称・ヒントが答えと一致・判定した難易度が指定どおり（1 つ下の難易度の手では解けない）・同じシードで同じ問題・ヒントを最後までたどると答えに着くこと、を確かめました。すべて合格。生成時間（Node、1 問）は かんたん 平均 4ms・ふつう 47ms・むずかしい 632ms（最大 2.3 秒）・達人 56ms。Worker で作るので、スマホで時間がかかっても画面は止まりません。
- **確認**: `npm run game-check -- nanpure`（自己テスト: タイトル → かんたんを開始 → 数字ボタンで正解 → 間違い（ミスが 1 増える）→ 戻す・やり直す → メモ・自動メモ → ヒント（説明が出て、数字が入る）→ 一時停止 → キーボードで最後まで解く → 結果画面 → 記録の保存 → 各難易度の問題・Worker での生成）。1440×900・390×844・1024×768・768×1024・844×390 で表示を確認。
- 保存（GK.store、`game:nanpure:`）: `save`（途中の問題）・`stats`（難易度ごとの記録）・`daily`（今日の一問の記録）・`dailyPuzzle`・`pool`（作り置き）・`bankIdx`・`settings`。
