# 花明かりの写真館（sakura-novel）

坂の町の小さな写真館を舞台にした、春のノベルゲーム（ADV）。物語・登場人物・音楽はすべてこのゲームのためのオリジナルです。

- 遊ぶ: `/games/sakura-novel/`
- ファイル: `public/games/sakura-novel/`（`index.html`・`data.js`・`script.js`・`game.js`・`style.css`・`icon.svg`・`images.json`）

## 概要

| 項目 | 内容 |
| --- | --- |
| ジャンル | ノベルゲーム（選択肢で結末が変わるアドベンチャー） |
| 分量 | 本文 約 14,500 字・533 ページ。1 周 約 16〜23 分（ルートにより） |
| 結末 | 4 つ（ノーマル・小春・灯・真の結末）。真の結末はほかの結末を見たあとに開かれます |
| 登場人物 | 水瀬湊（主人公・17 歳）、桐野小春（写真館の孫）、芹沢灯（古書店の娘）、桐野清（写真館の主人・78 歳）、芹沢春江（灯の祖母・74 歳） |
| 舞台 | 架空の坂の町「春見町」。桜並木の「花見坂」、坂の上の「桐野写真館」、駅前の古書店「坂下堂」、灯川の土手 |

## あらすじ

三月の終わり。両親の海外赴任で、高校生の湊は春休みのあいだだけ、叔母の住む坂の町・春見町に預けられる。桜並木の坂の上には、四月いっぱいで店を閉める古い写真館があった。

店の片づけを手伝うことになった湊は、写真館の孫・小春と一緒に、「未受取」の写真を持ち主に返してまわる。缶の底から出てきたのは、昭和四十八年の春、坂の大桜の下で笑う若い女性の写真。封筒には「ハルエ様」とだけ書かれ、裏には鉛筆で『来年も、この木の下で』。その写真を見た主人の清は、「それは、返さなくていい」とだけ言って口を閉ざす。

駅前の古書店の娘・灯と、その祖母・春江。暗室で清が口ずさむ鼻歌。五十年以上、毎年同じ日に撮られてきた大桜の写真。ばらばらの手がかりがひとつの絵になったとき、湊は、五十年遅れの約束のために、ある夜を用意する。

## システム

- **台本はデータ**: 物語は `script.js` の台本（独自の書式）で、エンジン（`game.js`）が解釈します。書式は `data.js` の冒頭に説明があります。`*ラベル`、`@bg`・`@show`・`@cg`・`@bgm`・`@se`・`@fx`・`@sepia`・`@tint`・`@petals`、`@set`（フラグ）・`@if`・`@jump`・`@choice`、`@chapter`・`@end`、`名前(表情)「台詞」`。
- **文章**: 名前の札つきのメッセージウィンドウ、1 文字ずつの表示（速さは 10 段階＋瞬間）、オート（待ち時間は 10 段階、文の長さに合わせて調整）、既読スキップ（読んだ文章だけ。既読はラベルごとに保存）、バックログ（最大 400 行。選んだ選択肢も記録）、ウィンドウを隠す。
- **セーブ / ロード**: 12 か所＋クイックセーブ＋オートセーブ（章のはじめと選択肢）。各データに、その場面の背景・立ち絵・イベント絵を描いた縮小画像（canvas で作成）、日時、章の名前、最後の文章を記録。上書きは確認つき。
- **演出**: 背景の切り替え（フェード・ワイプ・暗転・桜吹雪）、立ち絵（左・中央・右など 5 か所。表情の切り替えはクロスフェード、登場・退場・移動はなめらかに）、話している人物以外を少し暗く、イベント絵、フラッシュ・画面の揺れ、回想のセピア（ヴィネットとフィルムのちらつき）、夕方・夜の色かぶせ、canvas で描く桜の花びら（量は場面ごとに）、章の扉。
- **選択肢とフラグ**: 小春・灯への好感度（隠し値）と、三つの手がかり（ネガ・歌・日付）のフラグ。第六章の選択と好感度で結末が決まります。真の結末の選択肢は、結末を一度見たうえで三つの手がかりをすべて見つけたときだけ現れます。
- **記録（GK.store）**: 見た結末・イベント絵・到達した章・既読・設定・セーブデータ。ギャラリー（イベント絵 6 枚・エンディングリストとヒント）、シーン選択（到達した章から。結末の章は必要な好感度を入れて開始）。一度結末を見ると、タイトル画面の絵が変わります。
- **設定**: 文字の速さ・オートの速さ・BGM の音量・効果音の音量・ウィンドウの濃さ（見本の文章で確認しながら調整）。
- **音楽**: すべて GK.music で作曲した書きおろし 7 曲。テーマ曲（D の陽音階）は物語の中で「ふたりが作った歌」として登場し、オルゴール風の編曲（春江の歌）とエンディングの編曲で繰り返されます。ほかに日常（ハ長調）・回想（都節音階）・夕暮れ・夜桜。効果音はシャッター・ドアベル・紙・胸の鼓動など。
- **画面**: PC・横長では 16:9 の画面をレターボックスで表示し、文章はウィンドウを重ねて表示。スマホ・縦長では上に場面（横幅いっぱい、縦長に少し広げて背景をトリミング）、下に文章、いちばん下にクイックメニューを並べた縦向けの配置になります。

### 結末の条件

| 結末 | 条件 |
| --- | --- |
| NORMAL END「春を待つ封筒」 | 第六章で選んだ相手の好感度が足りないとき |

| AKARI END「川面の灯」 | 「灯さんと、春江さんを大桜へ連れていく」＋灯の好感度 2 以上 |
| TRUE END「花明かりの写真館」 | どれかの結末を見たあと、ネガ（第三章）・歌（第四章）・日付（第五章）の手がかりをすべて見つけ、第六章で現れる選択肢を選ぶ |

## 独自の要素（既存作品との違い）

- 物語は、恋愛を主軸にした学園ものではなく、**写真屋が預かった写真を持ち主に返す**という仕事を軸にした、世代をまたぐ「約束」の物語です。主人公たちの淡い恋と、五十年前の約束が重なり、真の結末で同じ言葉（「来年も、この木の下で」）が別の意味で回収されます。
- **テーマ曲そのものが謎の手がかり**: タイトル曲のメロディーが、暗室の鼻歌・川原の歌として物語に出てきて、プレイヤーも「聞いたことがある」と気づける作りです。
- 真の結末は、好感度を上げるだけでは開かれず、**三つの手がかりを選択肢で拾い集める**必要があります（片方の相手だけに寄りそうと集めきれないように配置）。
- 写真館らしい演出: シャッター音とフラッシュ、暗室の赤い光、回想のセピアとフィルムのちらつき、桜吹雪の場面転換。

## 画像

27 枚（背景 8・立ち絵 13（4 人）・イベント絵 4・キービジュアル・タイトル背景）。いまは画像サンプルで、立ち絵は名前つきのシルエット、背景・イベント絵は名前つきのカードとして表示されます。生成用のプロンプトは [prompts/sakura-novel.md](prompts/sakura-novel.md)。

| 種類 | ツール | そろえ方 |
| --- | --- | --- |
| 背景 8 枚・タイトル背景 | Midjourney（v7・`--style raw`） | 同じ言い回しと `--sref` で色調をそろえる |
| 立ち絵の基本の表情・イベント絵・キービジュアル | niji・journey | 人物設定を毎回同じ文で書き、`--cref` で人物をそろえる |
| 立ち絵の表情違い（9 枚） | Gemini | 基本の立ち絵を添付し、表情だけを変える |
| 古い写真（第一章の鍵の写真） | Adobe Firefly | 1970 年代のフィルム写真風 |

生成した画像を `public/games/sakura-novel/img/<name>.png` に置き、`npm run game-images -- sakura-novel` を実行すると、サイズを合わせた WebP に変換されます（立ち絵の白い背景は自動で切り抜かれます）。

## 技術メモ

- 構成: `data.js`（画像・人物・曲の一覧と台本のパーサー。ブラウザと Node の両方で読み込めます）、`script.js`（台本）、`game.js`（エンジン）。DOM と CSS で場面を組み立て、花びらとセーブの縮小画像だけ canvas を使います。外部のライブラリ・フォント・通信はありません。
- インタープリター: 非同期の命令ループ。ロードやタイトルへの移動のたびに世代番号を進め、古いループの待ちは捨てます。セーブデータは「ラベル名＋ラベル内の位置」と、場面の状態（背景・立ち絵・イベント絵・BGM・セピア・色かぶせ・花びら）・フラグ・直近のバックログ。
- 既読: ラベルの中は上から順に進むので、ラベルごとに「読んだいちばん先の位置」を保存しています。
- 台本の検査（Node）: パースエラー、存在しないラベル・画像・曲・効果音・話者・表情、ページの長さ、そして全ての選択肢の組み合わせを辿って「すべての道が結末に着く」「全ラベル・全命令に到達できる」「真の結末は結末を見る前には到達できない」ことを確認（1,314 通り）。
- 自動テスト（`window.__gameSelfTest`）: タイトル → はじめから → 文章を進める → 最初の選択肢を選んでフラグを確認 → バックログ → セーブして進めてからロードし、位置が一致することを確認 → セーブ画面・設定 → デバッグ用の入口（`window.__novel.newGame('normal_1')` など）からノーマルと真の結末まで進めて記録を確認 → クリア後のタイトル・ギャラリー。終わったら保存データを元に戻します。
- 音量: BGM・効果音の音量は kit の音楽 / 効果音のバス（`GK.audioOut('music' | 'sfx')`）のゲインを変えています。
