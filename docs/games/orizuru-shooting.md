# 千代紙飛行（orizuru-shooting）

折り鶴の縦スクロールシューティング。`public/games/orizuru-shooting/`

## 概要

和紙と千代紙でできた「紙の国」の空を、一羽の折り鶴になって飛ぶ弾幕系の縦スクロールシューティングです。三つの幕（ステージ）にはそれぞれ中ボスと「主（ぬし）」がいて、主は何段階かの「型」で弾幕を張ってきます。自機・敵・弾・爆発はすべてコードで描いた折り紙の多角形（面ごとに明るさを変えた「折り目の陰影」）で、背景の絵だけを画像にしています。

- 難易度：かんたん／ふつう／むずかしい（弾の速さ・密度・残機が変わり、むずかしいは撃ち返し弾あり）
- 記録：難易度ごとの最高得点（到達した幕・踏破したか）を保存
- 画面：タイトル → 第一幕〜第三幕 → 結果。一時停止からいつでも「最初から」「タイトルへ」

## 遊び方（操作）

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD（マウスのドラッグでも可） | 画面のどこでもなぞると、指が動いた分だけ鶴が動く（相対移動。指で鶴が隠れない） |
| ショット | Z（押している間）／タイトルで「自動連射」をオン | 指を置いている間は自動で連射 |
| 低速移動 | Shift | 「低速」ボタン（押している間） |
| 紙吹雪（ボム） | X ／ 右の「紙吹雪」ボタン | 「紙吹雪」ボタン |
| 一時停止 | Esc ／ P ／ 右上のメニュー | 右上のメニュー |

タイトル画面では ← → で難易度、Z / Enter で出発できます。

## ルール

- 当たり判定は鶴の中心の小さな点（半径 2.6）。低速移動中は白い点と輪で表示されます。
- 弾のすぐそばをかすめると「グレイズ」：得点 ＋200×倍率、倍率 ＋0.01。レーザーのそばでもグレイズします。
- 色紙（アイテム）：赤 ＝ パワー（＋0.05、大きいものは ＋0.50、最大 4.00）、青 ＝ 得点（下ほど安く、上で取ると 10,000×倍率）、緑 ＝ 紙吹雪 ＋1。点線より上に行くと、出ている色紙を全部吸い寄せます。
- パワー：1.00 で 2 連装、2.00 で斜め弾が追加、3.00 で子鶴 2 羽（追尾する鶴を飛ばす。低速中はまっすぐの針）、4.00 で子鶴 4 羽。
- 倍率（×1.00〜×5.00）：グレイズと青い色紙で上がり、被弾で −1.00、紙吹雪で −0.50。
- 紙吹雪：画面の弾を星（小さな得点）に変えて消し、約 3 秒無敵。敵とボスにもダメージ。被弾後は 3 つまで補充。
- 被弾：残機 −1、パワー −0.60（一部をばらまくので拾い直せる）。
- エクステンド：100 万・250 万・450 万点で残機 ＋1。
- 主の「型」：被弾も紙吹雪もなしで破ると撃破ボーナス（10 万 × 幕の番号）。各型には制限時間があり、時間切れでも次の型へ進みます。
- 幕の突破：突破ボーナス・パワーボーナス・その幕のグレイズ ×300。
- コンティニュー：3 回まで。得点は 0 に戻り、その場から再開します。

## 独自の要素（既存作品との違い）

- 世界・名前・キャラクターはすべてオリジナルです（紙の国、ハネマル・スミゴイ・カミナギ、型の名前）。巫女や既存の弾幕作品の見た目・用語（スペルカードなど）は使っていません。
- 見た目は「折り紙」で統一：自機は折り鶴、敵は紙飛行機・折り紙の蛙・金魚・舟・兜・手裏剣・黒い鶴、中ボスは紙風船・奴さん・風車。弾も折り目の付いた紙の形（米粒・菱形の鱗・花びら・折り鶴・紙の星）で、白い芯と濃い縁で背景から読み取りやすくしています。
- 紙吹雪のボム、紙片が裏返りながら舞う爆発、色紙のアイテムなど、紙の質感を演出に使っています。
- 音楽は陽音階・都節・短調で作曲したオリジナル（タイトル・各幕・主・突破のジングル）。

## 画像

画像は 7 枚（キービジュアル 1・各幕の背景 3・主の紹介カードの絵 3）。いまは画像サンプルで、遊ぶのに必要な絵はすべてコードで描いています。生成用のプロンプトは [prompts/orizuru-shooting.md](prompts/orizuru-shooting.md) にあります。

- Midjourney：キービジュアル、背景 3 枚（同じ設定でそろえる）
- ChatGPT：主の絵 3 枚（同じチャットで続けて生成し、質感と背景をそろえる）

背景は上下を反転しながらつないで縦にスクロールし、ゲーム側で薄く表示します（弾が見やすいように）。

## 技術メモ

- ファイル：`index.html`・`art.js`（折り紙の描画・弾の形・背景・BGM のデータ。`window.OZ`）・`game.js`（ゲーム本体）・`style.css`。
- 論理座標 360×640（9:16）の固定キャンバス（`GK.fit`）。PC は左右に HTML のパネル、縦長画面は上下にバー（`body.wide` / `body.tall` を JS で切り替え、フィールドの大きさを計算）。
- 弾・自機弾・粒子・アイテムはオブジェクトプール（配列の詰め直し＋使い回し）。弾の絵は種類×色ごとに画面の解像度で事前に描いたキャンバスで、`setTransform` ＋ `drawImage` の 1 回で描きます。静止した背景の層も画面解像度の帯に事前描画し、毎フレームは 2 回の転写だけ。
- 当たり判定は円（弾）と線分（レーザー）。被弾はフレームの最後にまとめて処理。`dt` が大きいフレームは 2 回に分けて更新。
- 敵の動き（曲線・停止・正弦・跳ねる・突進）と攻撃はデータ化した台本（`script()`）で時間順に出現。中ボスと主がいる間は台本の時間が止まります。
- 自己テスト（`window.__gameSelfTest`）：無敵・自動操縦でふつうを開始 → 弾を大量に出して描画時間を計測 → 第一幕の主まで進めて全部の型を破る → 突破 → 第三幕の主を倒して結果画面まで。ヘッドレスの Chrome（ソフトウェア描画）で弾 730 発のとき、1 フレームの JS の処理は約 3 ms（更新 0.8 ms・描画 2.3 ms）。
- 記録：`GK.store` の `best:<難易度>`、設定 `auto`（自動連射）・`diff`（最後の難易度）。
