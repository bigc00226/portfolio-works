# ロジック絵巻 ― 和のお絵かきロジック

`public/games/oekaki-logic/` ・ 遊ぶ: `/games/oekaki-logic/`

## 概要

数字を手がかりにマスを塗っていくと、和の絵が浮かびあがるお絵かきロジックです。富士山・招き猫・だるま・鯛・お寿司・桜・鳥居・提灯・柴犬・金魚・風鈴・五重塔・狐の面など、**31 問の絵をすべてこのゲームのために描き下ろしました**（5×5 入門 8 問・10×10 12 問・15×15 8 問・20×20 3 問）。どの問題も **1 行・1 列ずつ考えるだけで解け、答えはひとつ** です（Node の検証で全問を確認）。完成すると、黒いマスがくるりと裏返って色つきのドット絵になり、額に入って「絵巻」（ギャラリー）に飾られます。

## ルール

- 盤面の上（列）と左（行）の数字は、その並びで **続けて塗るマスの数** を、並んでいる順に表します。
- 「3 1」なら 3 マス続けて塗り、1 マス以上あけて 1 マス塗ります。「0」はその並びに塗るマスがないことです。
- すべての行・列のヒントに合うように塗ると完成です。× は「塗らない」と決めたマスの目印で、答えの判定には関係しません。

## 遊び方（操作）

| 操作 | マウス・タッチ | キーボード |
| --- | --- | --- |
| 塗る | タップ・クリック。なぞると縦か横にまっすぐ続けて塗れる。塗ったマスから始めると消す | `Z`・`スペース`・`Enter`（押したまま矢印で続けて） |
| × をつける | 「しるし」に切り替えてタップ、または右クリック | `X`（押したまま矢印で続けて） |
| 塗る / しるしの切り替え | 下（右）のボタン | `M` |
| 移動 | — | 矢印キー |
| 拡大・縮小・移動（15×15・20×20 など） | 2 本指でつまむ・2 本指で動かす、「拡大」「縮小」「移動」ボタン、マウスのホイール、中ボタンのドラッグ | `+`・`-` |
| 戻す・進む | 「戻す」「進む」 | `Ctrl`＋`Z`・`Ctrl`＋`Y` |
| ヒント | 「ヒント」 | `H` |

- 拡大しても、上と左のヒントの数字は画面の端に貼りついたまま一緒に動くので、いつでも読めます。
- 左上の小さな四角に、いまの塗り方が縮小して表示されます。
- マウスを乗せている（カーソルのある）行・列と、そのヒントを色で示します。
- 途中の問題は自動で保存され、一覧で「とちゅう」と表示されます。もう一度開くと続きから。
- 右上のメニューから「最初からやり直す」「設定」「一覧へ」。

### 便利な機能（設定）

| 項目 | はじめ | 内容 |
| --- | --- | --- |
| 終わった列に × を自動でつける | オン | ヒントの数どおりに塗れた行・列の、残りのマスに × をつけます |
| まちがいをすぐに知らせる | オフ | 塗ってはいけないマスを塗ると赤く光って × になり、まちがいの数を数えます |
| 選んでいる行・列を強調する | オン | カーソルの行・列とヒントに色をつけます |
| BGM を流す | オフ | 都節音階で作った静かなオリジナル曲 |

- **ヒントの数字のグレー表示**: 行・列がヒントどおりに塗れたら、その数字はうすくなります。端から × と黒で区切られて確定した数字も、ひとつずつうすくなります。
- **ヒント**: いま考えるとよい行・列（決まるマスがいちばん多いところ）を黄色で示し、決まるマス（■ と ×）を光らせて理由を説明します。「反映する」で塗れます。例:「上から 4 行目（ヒント 8）は、ヒントの長さが 10 マスのうち大きな部分を占めます。左に寄せても右に寄せても重なる、光っているマスは必ず塗られます。」まちがったマスがあるときは、先にその場所を教えます。

### 完成と絵巻

完成すると、ヒントと罫線が消え、マスが左上から斜めに裏返って色つきの絵になり、額に入って金の光がきらめきます。結果のカードに絵の名前・タイム・ベスト・使ったヒントの数が出ます。完成した絵は「絵巻」に色つきで並び（まだの絵は「？？？」）、絵を選ぶと大きく見たり、もう一度解いたりできます。

## 独自の要素（既存作品との違い）

お絵かきロジック（ノノグラム）というパズルの形式は一般的なものですが、名前・問題・絵・画面はすべてこのゲームのものです。

- 名前「ロジック絵巻」、31 問の絵（和のモチーフのドット絵とその配色）はすべてオリジナルです。既存のアプリ・雑誌の問題や、既存作品のキャラクター・ロゴは使っていません。
- 完成すると絵巻に飾られていく「集める楽しみ」と、マスが裏返って色づく演出。
- 拡大してもヒントが端に残る盤面、なぞるだけの入力、理由を説明するヒントで、スマホでも 20×20 を遊べます。

## 技術メモ

- ファイル: `index.html`・`style.css`・`game.js`（画面・canvas の盤面）・`logic.js`（ヒントの数字の作成・行の論理解法・ヒント・数字のグレー表示の判定。DOM を使わない純粋なモジュールで、ブラウザと Node で共通）・`puzzles.js`（31 問の絵と配色）・`icon.svg`・`images.json`。
- **問題のデータ**: 1 問は文字の行の並び（`.` が空白、ほかの文字が色）と、文字ごとの色・背景色。ヒントの数字は絵から自動で作ります。
- **行の論理解法**: 1 本の行（列）について、ヒントの置き方のうち、いま分かっているマスと矛盾しないものすべてを、左からと右からの動的計画法でまとめ、「どの置き方でも黒」「どの置き方でも白」のマスを決めます。これを行と列に、変化がなくなるまでくり返します（仮定や総当たりは使いません）。
- **検証（Node）**: 全 31 問について、行の長さ・色の定義・ID の重複がないこと、行の論理解法だけで最後まで解けて、結果が絵と一致すること（＝答えがひとつ）を確かめました。最初に描いた絵のうち 7 問は途中で止まったので、解法の結果（決まらないマス）を見ながら絵を直しました（耳の形・泡の数・風鈴のふち・紅葉の葉先・月見台の脚・ひげの幅など。桜の枝は一輪の満開の桜に描き直し）。いまは全問合格。
- **ヒント**: プレイヤーの正しいマスだけを手がかりに全行・全列に行の解法をかけ、新しく決まるマスがいちばん多い行・列を選びます。正しいマスが増えるほど決まることも増える（単調）ので、解ける問題なら必ず次の一手が見つかります。
- **盤面**: canvas（`GK.fit`）。ヒントの帯は拡大・移動しても上と左に固定、5 マスごとの太線と色分け、なぞりは最初に動いた向き（縦・横）に固定。2 本指のつまみで拡大（指の間の点を中心に）。
- **確認**: `npm run game-check -- oekaki-logic`（自己テスト: 一覧のカードから 5×5 を開く → なぞって 1 行を塗る → 戻す・進む → 右クリックで × → ヒント（説明が出て反映される）→ 最後のマスをクリックして完成 → 裏返りの演出と結果カード → 記録の保存 → 20×20 を開いて拡大・縮小・なぞり → 絵巻）。1440×900・390×844・1024×768・768×1024・844×390 で表示を確認。
- 保存（GK.store、`game:oekaki-logic:`）: `rec`（完成した絵・ベスト）・`prog`（とちゅうの盤面）・`settings`・`tab`。
