# 番狂わせ大富豪 ― 大富豪（大貧民）vs 3 CPU

`public/games/daifugo/` ・ 遊ぶ: `/games/daifugo/`

## 概要

トランプの「大富豪（大貧民）」を、個性の違う 3 人の CPU と 4 人で遊ぶブラウザゲームです。手札を早くなくした順に大富豪・富豪・貧民・大貧民になり、3・5・10 試合の合計点で最終順位を決めます。革命・8切り・11バック・しばり・スペ3返し・都落ち・反則上がり・7渡し・10捨てをルール設定で切り替えられます。

- 画面：タイトル（強さ・試合数・ルール設定）→ 配る → カード交換（2 試合目から）→ 対戦 → 試合の結果 → 最終結果
- トランプ 53 枚（ジョーカー 1 枚）はすべてコードで描いています（数字札のマーク配置、J・Q・K の図案、ジョーカー、裏面）。画像は背景・キービジュアル・CPU の顔（3 人 × 3 表情）だけです。
- PC（1440×900）・スマホ縦（390×844）・中間の大きさ（1024×768・768×1024・844×390）で、スクロールなしに収まるようにレイアウトを切り替えます（横長：左・上・右に CPU、縦長：上に 3 人を並べる）。

## 遊び方（操作）

- 手札をクリック／タップで選び（もう一度で解除）、下のバーの **出す**。いま出せない札は暗くなり、選んだ組み合わせが出せるときだけ「出す」が押せます（バーに「♠5 ♦5（ペア）」のように表示）。
- **パス**（場に札があるとき）・**並べ替え**（強さ順 ⇄ マーク順）・**ヒント**（おすすめの出し方を選んでくれる）。
- キーボード：<kbd>←</kbd><kbd>→</kbd> で札を移動、<kbd>Space</kbd>／<kbd>↑</kbd> で選ぶ、<kbd>Enter</kbd> で出す、<kbd>P</kbd> パス、<kbd>S</kbd> 並べ替え、<kbd>H</kbd> ヒント、<kbd>Esc</kbd> 選択を解除。
- カード交換・7渡し・10捨てでは、渡す（捨てる）札を指定の枚数だけ選んで「渡す」「捨てる」。
- 反則上がりになる出し方をしようとすると、確認のダイアログが出ます。
- 右上：メニュー（中断してタイトルへ）・遊び方（いまのルール設定つき）・音のオン／オフ。

## ルール（採用したルール）

**基本**

- 4 人（あなた → ハヤテ → シオン → ゴンゾウ の順）。トランプ 52 枚＋ジョーカー 1 枚を配ります（14・13・13・13 枚）。
- 強さ：3 < 4 < … < 10 < J < Q < K < A < 2 < ジョーカー。ジョーカーは 1 枚で出すといちばん強く、組の中では好きな札の代わりになります。
- 出せる組：1 枚／同じ数字の 2〜4 枚（ジョーカー入りは 5 枚まで）／**階段**＝同じマークの 3 枚以上の連番（ジョーカーで穴埋め・延長できる。A-2-3 のように 2 をまたいでつなげることはできません）。
- 前の人と同じ組・同じ枚数で、より強いものを出すか、パス。最後に出した人以外の全員がパスしたら場が流れ、最後に出した人から始めます。一度パスするとその場が流れるまで出せません（公式ルールと同じ。設定でオフにすると、ほかの人が出せばまた出せます）。上がった人が最後に出した札で場が流れたときは、その次の人から始めます。
- 最初の試合は ♦3 を持っている人から（公式ルールでは ♠3、地域によって ♦3。♦3 を含めて出す必要はありません）。2 試合目からは前の試合の大貧民から始めます。
- 順位と点：大富豪 3 点・富豪 2 点・貧民 1 点・大貧民 0 点。4 人なので平民はいません（平民は 5 人以上のときの身分）。最終順位は合計点、同点なら最後の試合の順位が上のほう。
- **カード交換**（2 試合目から）：大貧民は大富豪に、いちばん強い札 2 枚を自動で渡し、貧民は富豪に 1 枚を渡します。大富豪・富豪は、要らない札を同じ枚数だけ選んで返します。

**ローカルルール**（タイトルの「ルール設定」で切り替え。初期値）

| ルール | 初期値 | 内容 |
|---|---|---|
| 革命 | あり | 同じ数字 4 枚以上（ジョーカー入り可）で強さが逆になる。もう一度革命が起きると元に戻る（革命返し）。ジョーカーは革命中もいちばん強い |
| 階段革命 | なし | 5 枚以上の階段でも革命 |
| 8切り | あり | 8 を含む札（ジョーカーが代わりをした 8 は含まない）を出すと場が流れ、出した人から始める |
| 11バック | あり | J を含む札を出すと、場が流れるまで強さが逆になる（革命中なら元の順に戻る。もう一度 J で解除） |
| しばり | あり | ジョーカーを含まない札が、前の札とまったく同じマーク（ペアならマークの組）で続いたら、場が流れるまでそのマークしか出せない。ジョーカーはしばりの中でもマークの代わりに出せる |
| スペ3返し | あり | ジョーカー 1 枚出しに、♠3 を 1 枚出して勝てる。そのまま場が流れる |
| 都落ち | あり | 前の試合の大富豪が 1 番に上がれなかったとき（ほかの人が先に 1 番で上がった時点で）、大富豪はその場で大貧民になる |
| 反則上がり | あり | ジョーカー・2（革命・11バック中は 3）・8（8切りありのとき）・スペ3返しの ♠3 を含む札で上がると、最下位になる |
| パスしたら場が流れるまで出せない | あり | 一度パスすると、その場が流れるまで出せない（自分の番は自動でパス）。オフにすると順番が来ればまた出せる |
| 7渡し | なし | 7 を出したら、出した 7 の枚数だけ好きな札を次の人に渡す |
| 10捨て | なし | 10 を出したら、出した 10 の枚数だけ好きな札を捨てる |

## 独自の要素（既存作品との違い）

- 舞台は「夜の喫茶店で開かれる大富豪の卓」。CPU は 3 人ともこのゲームのオリジナルで、打ち方の個性が違います。
  - **ハヤテ**（商店街の配達少年・速攻派）：弱い札からどんどん出し、枚数の多い出し方と 8切りを好み、なかなかパスしない。
  - **シオン**（眼鏡の大学生・慎重派）：2 やジョーカーなどの強い札を温存し、早いうちはパスして流れを読む。
  - **ゴンゾウ**（喫茶店のマスター・一発逆転派）：ペアや 3 枚出しを好み、手札が弱いほど革命を狙う。
- 3 人の顔は「ふつう・うれしい・くやしい」の 3 表情で、革命・8切り・上がり・都落ちなどの出来事に合わせて変わり、短い台詞を話します。
- 革命中は卓の色が紫に変わり、場の上に「革命中・11バック・しばり ♥」などの状態と、いま場に出ている組（「ゴンゾウ：ペア」）を常に表示します。
- 出せない札を暗くし、選んだ札が出せる組かどうかをバーに表示するので、ローカルルールに慣れていなくても迷いません。ヒントボタンもあります。
- BGM は新しく作った曲（タイトル・対戦の 2 曲）を WebAudio で合成しています。
- 戦績（強さごとの優勝回数・最高点・大富豪になった回数）と設定を保存します。

## 画像

画像の一覧と生成プロンプトは [prompts/daifugo.md](prompts/daifugo.md)（`npm run game-images -- daifugo` が images.json から書き出します）。全 11 枚。

| 画像 | 枚数 | ツール | そろえ方 |
|---|---|---|---|
| キービジュアル `key-visual`（1600×900） | 1 | Midjourney v7 | 夜の喫茶店とトランプ。中央上に余白 |
| 背景 `bg-table`（緑のフェルト、1600×900） | 1 | Leonardo.Ai | テクスチャとして均一な布地 |
| CPU の顔 `cpu-<名前>-normal`（512×512） | 3 | niji・journey | 3 人の基準の絵。シオン・ゴンゾウはハヤテの画像を `--sref` にして絵柄をそろえる |
| CPU の表情 `cpu-<名前>-happy` / `-angry`（512×512） | 6 | Gemini | 基準の `-normal` を添付し、表情だけを変える編集で同じ人物のまま作る（`ref`） |

トランプの札そのものは画像を使わず、すべてコードで描いています。

## 技術メモ

- 構成：`index.html`・`style.css`・`rules.js`（札・出せる組の判定・場の進行・順位・カード交換・CPU。DOM を使わない純粋なモジュールで、ブラウザでは `window.DaifugoRules`、Node では `require`）・`game.js`（canvas の卓・札の描画・アニメーション・入力・進行・画面）。共通部品は `public/shared/games/kit.js`（GK）。
- 札の描画：数字札のマーク（パスで描いた ♠♥♦♣）を標準的な配置で、J・Q・K は上下対称の図案（王冠・ティアラ・羽根つき帽子）、ジョーカーは放射状の模様と道化の帽子。大きさごとに 1 度だけ描いて、オフスクリーン canvas にキャッシュします。
- 進行：`applyPlay`（札を出す・革命・11バック・しばり）→ 7渡し／10捨ての札を選ぶ → `finishPlay`（上がり・反則上がり・都落ち・8切り・次の手番）と `pass`（全員パスで場が流れる）の 2 段階。画面は返ってきたイベント（革命・8切り・しばり…）を順に演出します。
- CPU：出せる組をすべて列挙し、「残りの手札を出し切るのに必要な手数の見積もり（ペア・階段のまとまりを考える）」「強い札を使うもったいなさ」「出せる枚数」「8切り・革命で得をするか」で点をつけ、パスの点と比べます。手札 0 枚になる正しい上がりがあれば必ず上がり、反則上がりは避けます。
  - やさしい：評価のゆらぎが大きく、ときどき気まぐれにパス。
  - ふつう：ゆらぎ小。
  - つよい：ゆらぎなし＋札を数える（自分以外の手札にそれより強い札が残っていない「止まる」出し方を高く評価）。
  - 性格（ハヤテ・シオン・ゴンゾウ）は、出す枚数・強い札を使う重み・パスのしやすさ・8切りと革命の好みを変えています。
  - Node での CPU 4 人のシミュレーション（600 試合）で、つよい 1,016 点 > ふつう 933 点 > やさしい 819・832 点の順になることを確かめました。
- 検証：
  - `rules.js` のユニットテスト（Node）：札の読み取り（ペア・ジョーカー入り・階段の穴埋めと両端、2 をまたがない）、強さの比較（革命・11バック・その重なり）、スペ3返し、しばり（かかる条件・ジョーカー）、8切り・上がり・都落ち・反則上がり（革命中は 3）、革命と階段革命、7渡し・10捨て、パスしたあとの出し直しの可否、出せる組の列挙、いろいろなルール設定で CPU どうし 2,000 試合を最後まで進めて順位が 0〜3 にそろうこと。
  - `npm run game-check -- daifugo`：PC とスマホの大きさでエラー・スクロールなし。`window.__gameSelfTest` がタイトルで強さと試合数をクリックで選び、canvas へのタップで札を選んで「出す」を押し、CPU の応手を待ち、残りを自動で進めて 3 試合の結果（合計 18 点）と最終結果を確かめ、タイトルに戻ります。
  - 1024×768・844×390・768×1024 でも puppeteer で、対戦・カード交換・結果の画面を撮って確認しました。
