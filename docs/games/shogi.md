# 縁側将棋（shogi）

`public/games/shogi/` ― 本将棋 vs CPU

## 概要

夏の夕方、古い家の縁側で指す本将棋です。対局相手は、縁側に住みついた三毛猫の「たま」（入門）、近所の小学生「そうた」（初級）、大学将棋部の「千景」（中級）、この家の主のおじいさん「源三」（上級）の 4 人。平手（先手・後手・振り駒）と 6 種類の駒落ちで対局でき、待った・ヒント・棋譜（コピーと再生）・相手ごとの成績が付いています。盤と駒はすべてコードで描いています。

## 遊び方（操作）

- タイトルで「対局相手」「手合い」「手番（駒落ちでは立場）」を選び、「対局開始」。途中でやめても「続きから」で再開できます。
- 自分の駒をタップ（クリック）すると、動かせるマスに印が付きます。行き先をタップすると指せます。ドラッグして置くこともできます。
- 持ち駒は、駒台の駒を選んでから打ちたいマスをタップ（またはドラッグ）。
- 成れるときはダイアログで「成る／成らない」を選びます。行き所のなくなる駒は自動で成ります。
- **待った**：自分の最後の手まで戻します（相手が考えている途中なら、その考えを取り消して戻します）。**ヒント**：CPU（中級の強さで約 1 秒）が考えたおすすめの手を矢印で示します。**投了**：確認のうえ負けで終わります。
- 終局後は「盤面を見る」で、棋譜の行をクリック、または ◀ ▶（キーボードの ← →）で 1 手ずつ再生できます。棋譜はメニューまたは棋譜欄の「コピー」でテキストとしてコピーできます。
- キーボード：矢印キーでカーソル、Enter / Space で選ぶ・指す、D で持ち駒を順に選ぶ、Z（Backspace）で待った、H でヒント、Esc で選択の解除。
- PC（横長）では盤の左上に相手の顔と駒台、右下に自分の駒台、右側に棋譜。スマホ（縦長）では盤を画面いっぱいにして、相手の駒台を上・自分の駒台を下に置き、棋譜は下のボタンから引き出しで開きます。

## ルール（採用したルール）

日本将棋連盟の公式ルールに沿っています（`rules.js`）。

- 駒の動き・成り：敵陣（相手側の 3 段）に入る・敵陣の中で動く・敵陣から出る手で成るかどうかを選べます。行き所のない駒（1 段目の歩・香、1〜2 段目の桂）は必ず成ります。
- 持ち駒：取った駒は持ち駒になり、空いているマスに打てます。行き所のない場所への打ち込み、**二歩**、**打ち歩詰め**は反則なので、指せる手の候補に出てきません（突き歩詰め・打ち歩の王手は可）。
- 自分の玉を取られる状態にする手は指せません。王手がかかると「王手」の表示と効果音が出ます。
- **詰み**で勝敗が決まります（指せる手がない状態はすべて負け）。**投了**もできます。CPU（中級・上級）は、自分の詰みを読み切ると投了します。
- **千日手**：同じ局面（盤・持ち駒・手番）が 4 回現れたら引き分け。その間、一方の指し手がすべて王手だった場合は**連続王手の千日手**として、王手をかけ続けた側の負けです。
- **持将棋（入玉宣言・点数計算）は扱いません**。代わりに 512 手に達したら引き分けにしています。
- 駒落ち：香落ち（上手の 1 一の香を落とす）・角落ち・飛車落ち・二枚落ち（飛・角）・四枚落ち（飛・角・両香）・六枚落ち（飛・角・両香・両桂）。駒落ちでは**上手（駒を落とした側）が先に指します**。上手は後手の位置（△）、下手は先手の位置（▲）として扱い、棋譜も △ が先に来ます。プレイヤーは下手・上手のどちらでも指せます（上手のときは盤を反転して自分の駒を手前に表示）。
- 棋譜の表記：▲７六歩・△同　銀・５八金右・４八金直・２二角成・同　角不成・４五桂打 などの公式の表記法（「同」、「打」は盤上の同じ駒も動ける場合だけ、成・不成、上・寄・引・右・左・直による区別）。

## 独自の要素（既存作品との違い）

- 舞台・キャラクター・セリフはすべてオリジナル（縁側の三毛猫・小学生・大学生・おじいさん）。対局中は相手が吹き出しで話し、王手・終局でセリフが変わります。
- 盤（柾目の木目を手続き的に描画）・五角形の駒・駒台・矢印・スタンプはすべて canvas で描いています。成駒は赤の一文字（と・杏・圭・全・馬・龍）、相手の玉は「王」、自分は「玉」。
- BGM は陽音階（D・E・G・A・B）で作曲したオリジナルの琴風の曲（タイトル用と対局用）。対局中はときどき風鈴が鳴ります。効果音（駒音・駒を取る音・王手の太鼓）も WebAudio で合成しています。
- 既存の将棋アプリの名前・画面・キャラクターは使っていません。

## 画像

画像は 7 枚（キービジュアル・背景・対局相手 4 人・風鈴の飾り）。いまは画像サンプルで、駒・盤はコードで描くため、サンプルのままでも遊べます。

- 生成プロンプト：[prompts/shogi.md](prompts/shogi.md)
- ツール：Midjourney（キービジュアル・和室の背景）、niji・journey（4 人の顔。1 枚目を `--sref` にして絵柄をそろえる）、ChatGPT（透過 PNG の風鈴）

## 技術メモ

- ファイル：`rules.js`（ルール。ページ・Worker・Node で共通の UMD）、`ai.js`（思考）、`worker.js`（Web Worker）、`game.js`（画面・入力・対局の流れ）、`style.css`、`images.json`。
- 盤は 81 マスの配列、駒は「種類 | 色 << 4」の整数、指し手は「from | to << 7 | 成り << 14」（駒打ちは from = 80 + 駒の種類）。局面は Zobrist ハッシュ（32 ビット × 2、持ち駒・手番を含む）で、千日手の判定と置換表に使います。
- 合法手：疑似合法手を作り、指してみて自玉に利きがないかで判定。歩を打って王手になる手だけ、相手に応手があるかを調べて打ち歩詰めを除きます。
- CPU（`ai.js`）：
  - 評価関数：駒の価値（盤上・持ち駒別）＋ 敵玉への近さ（攻め駒）・自玉への近さ（守りの金銀）＋ 玉の位置（上がりすぎの減点）＋ 飛角の利きの数。
  - 入門：合法手にランダムな点数を付け、ただで取れる駒・1 手詰めを優先（取られる場所への移動はたまに気にしない）。
  - 初級：2 手読み＋静止探索（駒の取り合いを最後まで）＋評価のゆらぎ（約 0.6 秒）。
  - 中級：反復深化のアルファベータ探索（PVS）＋静止探索＋指し手の並べ替え（取る手 MVV-LVA・キラー手・ヒストリー）＋王手の延長（約 1.5 秒）。
  - 上級：上記＋置換表（2^20 エントリー）・ヌルムーブ枝刈り・後半の手の削減（LMR）（約 3 秒）。序盤だけ小さなゆらぎを入れて毎回同じ将棋にならないようにしています。
  - Node での自己対局（両方の色で 1 局ずつ）で、初級 > 入門、中級 > 初級、上級 > 中級 を確認しました。
- 思考は Web Worker で行い、画面は固まりません（上級の思考中の描画の最大間隔 67 ms をヘッドレス Chrome で確認）。Worker が使えない環境では、ページの中で短い時間（最大 0.9 秒）だけ考えます。
- 検証：
  - perft（初期局面からの合法手の総数）を Node で確認：深さ 1 = 30、2 = 900、3 = 25,470、4 = 719,731（約 0.25 秒）。駒落ちの各初期局面でも深さ 2 を確認。
  - 単体テスト：SFEN の往復、指す／戻すでハッシュが戻ること、強制成り、桂の打ち場所、二歩、打ち歩詰め（反則）と打ち歩の王手（合法）、突き歩詰め（合法）、詰みの判定、千日手（12 手で 4 回目）、連続王手の千日手（王手側の負け）、棋譜の表記（同・成・不成・打・右・左・直・上手側から見た左右・龍の左右）。
  - `npm run game-check -- shogi`：PC・スマホでタイトル → タップで ▲７六歩 → CPU の応手 → ドラッグで指す → ヒント → 待った → 成りの選択 → 1 手詰めで勝ち → 結果 → 棋譜の再生、まで自動で実行。1024×768・768×1024・844×390 と、上手（盤の反転）・駒落ちの開始も別のスクリプトで確認。
