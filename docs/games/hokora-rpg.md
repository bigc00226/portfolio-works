# 宵灯りのほこら（よいあかりのほこら）

`public/games/hokora-rpg/` ― 妖（あやかし）の里をめぐる、20〜40 分で遊びきれる和風コマンドバトル RPG。

## 概要

- ジャンル：見下ろし型マップ＋ターン制コマンドバトルの RPG（1 人用・オリジナル作品）
- プレイ時間：20〜40 分（はじめから〜エンディングまで）
- 舞台：山あいの「灯ノ里（ひのさと）」、野原「灯ノ野」、ダンジョン「宵ノ森」「鳴き岩の洞」、最後の「奥ノ祠」
- 仲間：コハル（祠守の見習い）・ゲンタ（木こり）・スズ（鈴の付喪神）の 3 人が、物語の進行で加わります
- 記録：記録の灯籠で 3 つのスロットに記録＋場所を移るたびのオート記録。クリア回数・最速クリア時間も残ります
- 画面：PC（1440×900）・スマホ縦（390×844）・タブレット・スマホ横で崩れないレイアウト。タッチ端末では十字キーと A / B ボタンが出ます

## あらすじ

山あいの小さな里、灯ノ里。里の奥山の祠には『宵灯（よいあかり）』という灯がともり、千年のあいだ、人の里と妖の住む山との境をやさしく照らしてきました。

ある晩、その灯がふっと消えます。妖たちは心が濁って荒れはじめ、里の畑にまで下りてくるように。祠守である祖母ヨネは腰を痛めていて山へ行けません。見習いのコハルは、宵灯をともし直すのに必要な二つのもの ―― 祠の鈴に宿る付喪神「スズ」と、洞の奥に納められた「火種石」 ―― を求めて旅に出ます。

森の入り口で妖に囲まれていた木こりのゲンタを助け、ねじれ樫に捕らわれていたスズを救い、鳴き岩の洞の主から火種石を取りもどし、三人は灯を喰らう影「宵喰らい」が待つ奥ノ祠へ。宵喰らいは、灯のない夜にひとりぼっちで生まれた影でした。

## 遊び方（操作）

| 操作 | キーボード | マウス・タッチ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD（Shift で小走り） | 画面を押したままにすると、その方向へ歩く／十字キー |
| 決定・話す・調べる | Z / Enter / Space | となりの人・宝箱・看板をタップ／A ボタン |
| キャンセル・メニュー | X / Esc（C でもメニュー） | 右上のメニューボタン／B ボタン |
| メニューの項目 | ↑↓（←→ でページ送り・設定の切り替え） | 項目をタップ（窓の外をタップでもどる） |

- 右上の丸ボタン：メニュー・遊び方・音の切り替え（共通部品）
- 会話は文字が 1 文字ずつ出ます。決定で全文表示、もう一度で次へ。文字の速さはメニューの「せってい」で変えられます

## システム

- **マップ**：16×16 のタイルをコードで描いたドット絵。カメラはなめらかに追従し、マップが画面より小さいときは周りを森や岩壁の模様で埋めます。仲間は先頭のうしろを列になってついてきます
- **建物と移動**：家・宿屋は扉で中に入れます。店（武器・防具・道具）は軒先のカウンター越しに話しかけます。マップの端や扉で切り替わるたびにオート記録
- **記録の灯籠**：手を合わせると HP と気が全回復し、3 つのスロットに記録できます（里・家・宿屋・峠の茶屋・森・洞・祠に設置）
- **戦闘**：ランダムエンカウント（草むら・森・洞・祠。道の上は出にくい）。コマンドは「こうげき・わざ・どうぐ・まもる・にげる」。素早さ＋運で行動順が決まります
- **わざと気**：わざは「気」を使います。属性は 火・風・雷・灯 の 4 つで、弱点をつくと 1.5 倍、耐性があると半分
- **状態**：毒・眠り・しびれ・暗闇、力↑・守↑・守↓。「まもる」でダメージ半分、ゲンタの「仁王立ち」は仲間への単体攻撃を引き受けます
- **成長**：経験値は生きている仲間全員にそのまま入ります。レベルアップの画面で能力の伸びと新しいわざを表示
- **装備**：武器（仲間ごとに種類が決まっている）・防具・飾りの 3 か所。店では装備できる仲間の能力の変化（攻 8→13↑ など）を表示し、買ってすぐ装備できます
- **ボス**：3 体のボスは行動パターンを持ち、HP が減ると第 2 段階に変化（2 回行動・新しい技）。最後のボスは姿と名前が変わります
- **力つきたとき**：最後の記録（オートを含む最新のもの）から、HP と気が回復した状態で再開
- **クリアの記録**：クリア回数・最速クリア時間・最後のクリアのレベルを保存し、タイトルの「クリアの記録」で見られます

### 妖（敵）

野原：ちょうちんねずみ・かかしぼう・ほおずき火／森：こけだるま・かさまる／洞：いわがに・かぜつづみ／祠：やみこま・かげどうろう。ボス：ねじれ樫（森）・はんざき大主（洞）・宵喰らい（祠）。

## 独自の要素（既存作品との違い）

- **世界と物語はすべてオリジナル**：灯ノ里・宵灯・祠守・付喪神のスズなど、名前も人物も新しく作りました。妖は民話の雰囲気（提灯・案山子・ほおずき・狛犬・石灯籠・小鼓・オオサンショウウオ）を下敷きにした新しいデザインで、既存のゲームのモンスターには似せていません
- **「倒す」ではなく「しずめる」**：妖は宵灯が消えて心が濁っただけ。勝つと「おとなしくなって、去っていった」と表示され、最後の敵も救われて終わります
- **コマンドと用語**：「こうげき・わざ・どうぐ・まもる・にげる」、魔力は「気」、お金は「文」、セーブは「記録の灯籠」
- **見た目**：窓は藍色に金の細い線と組紐の結び目のような角飾り、カーソルは小さな炎。戦闘は仲間を顔つきのカードで並べ、敵はイラストで表示
- **パズル**：森の三つの灯籠に火をともして霧を晴らす／洞の岩を押して穴を埋める（看板からいつでも岩を元にもどせるので詰まりません）／祠の左右の影灯籠を祓って結界を解く
- **音楽**：BGM 13 曲（タイトル・家・里・野原・森・洞・祠・戦闘・ボス・最後のボス・勝利・力つきたとき・エンディング）と効果音は、すべて Web Audio で合成した新しい曲です。陽音階・都節（陰音階）で作曲しています

## 画像

画像は 25 枚（キービジュアル・タイトル背景・エンディング・戦闘背景 4・仲間の顔 3 人×2 表情・敵 9・ボス 3）。いまは画像サンプルで、AI ツールで生成するためのプロンプトは [prompts/hokora-rpg.md](prompts/hokora-rpg.md) にあります。

| 組 | ツール | そろえ方 |
| --- | --- | --- |
| キービジュアル・エンディング・仲間の顔（ふだん） | niji・journey | 顔を先に作り、`--cref` で参照してキービジュアル・エンディングの人物をそろえる |
| 顔の表情違い（3 枚） | Gemini | ふだんの顔の画像を添付して「表情だけ変えて」と編集 |
| タイトル背景・戦闘背景 4 枚 | Midjourney | 同じ構図（手前が平らな舞台）・同じタッチで |
| 敵・ボス 12 体 | ChatGPT | 同じ会話の中で続けて作り、透過 PNG で |

マップのタイル・歩く人物・宝箱・灯籠・鳥居などはコードで描いたドット絵なので、画像を差し替えなくても完成した見た目になります。

## 技術メモ

- ファイル：`data.js`（仲間・わざ・道具・敵・遭遇表と、ダメージ計算・敵の行動・自動戦闘の純粋な関数）、`maps.js`（マップの文字列と物の配置）、`gfx.js`（タイル・人物・飾り・窓の描画）、`audio.js`（BGM と効果音）、`engine.js`（入力・窓・マップ・メニュー・店・記録・タイトル・エンディング・デバッグ・自己テスト）、`battle.js`（戦闘）、`story.js`（イベントと会話）
- 画面：論理解像度は「最小 320×240」で、画面の縦横比に合わせて最大 432×420 まで広げます（横長の PC では 384×240、縦長のスマホでは 320×420 前後）。ドット絵はにじまないよう拡大し、文字は高解像度のまま描きます
- `data.js` と `maps.js` は DOM を使わない純粋なデータと関数なので、Node でもそのまま読み込めます。戦闘の計算（`HR.resolve`・`HR.enemyChoose`・`HR.endRound`）はゲームとシミュレーションで同じコードです

### バランス調整の方法

1. **シミュレーション**（Node）：`data.js` を読み込み、物語の流れ（野原 3 戦 → ゲンタ加入 → 森 9 戦 → ねじれ樫 → スズ加入 → 洞 11 戦 → はんざき大主 → 祠 5 戦＋影灯籠 2 戦 → 宵喰らい）を、`HR.autoChoose`（回復を優先し、ボスには大技を使う簡単な AI）で 400 回通しで遊ばせ、区間ごとの「レベル・勝率・1 戦の手番数・戦闘後の HP 残り・お金」を集計しました。店での買い物と宝箱の装備も再現しています
2. **目標値**：ふつうの戦闘は 2〜3 手番で HP が 2〜3 割減る程度。ボスは想定レベル（森 Lv 5〜6・洞 Lv 9〜10・祠 Lv 12〜13）で勝率 80〜97%、5〜8 手番
3. **調整後の結果**（400 回の平均）：ねじれ樫 勝率 99%・7.6 手番／はんざき大主 97%・6.6 手番／宵喰らい 85%・5.9 手番。通しでの全滅は平均 0.2 回。最初の野原の戦闘は Lv 1 でもほぼ負けないようにしてあります
4. **詰まり防止**：記録の灯籠で全回復、力つきても回復した状態で再開、洞の岩は看板で元にもどせる、宿屋のお金が足りなくても灯籠で回復できる、里帰りの札で里にもどれる

### 確かめたこと

- `npm run game-check -- hokora-rpg`：PC・スマホでエラーなし・スクロールなし・画像サイズ一致。自己テスト（`window.__gameSelfTest`）で、はじめから → 会話 → 家を出て里を歩く → メニュー → 戦闘（自動）→ 記録して読みこみ、まで
- `?debug=1` を付けて開くと、メニューに「デバッグ」（ワープ・進行度の設定・レベル +3・お金・エンカウントの切り替え・テスト戦闘・全回復）が出ます。`?debug=1&start=3` のように進行度を指定して始めることもできます
- 通しのテスト（puppeteer）：はじめから、実際の扉・トリガー・灯籠・しめ縄・岩押し・影灯籠・ボス 3 体を通って、エンディングとクリアの記録まで進むことを確認
- マップの検査（Node）：各マップの行の長さ・扉とワープの行き先・物語の各段階でイベントや宝箱に歩いて届くか（幅優先探索）

## 攻略メモ（クリアまでの流れ）

1. **ヨネの家**：話を聞いて、よもぎ団子 3 つと 50 文をもらう。家の灯籠で記録できる
2. **灯ノ里**：鍛冶屋で「樫の杖」、仕立て屋で「旅の羽織」を買っておくと楽。里の南から野原へ
3. **灯ノ野**：道を南へ。橋を渡ると宵ノ森の入り口。北の草むらの宝箱に「お守り」
4. **宵ノ森**：入り口でゲンタが妖に囲まれている → いっしょに戦って仲間に。三つの石灯籠（西・東・北西）に火をともすと霧が晴れる。霧の前の灯籠で記録してから奥へ。ねじれ樫は火に弱い（火の粉・かんしゃく玉）。勝つとスズが仲間に
5. **里で支度**：店に新しい品が入る（鋼の斧・銀の祓串・銅の鈴・刺し子の上着など）
6. **峠のしめ縄**：野原の東、峠の茶屋の先。スズがいるとほどける
7. **鳴き岩の洞**：岩の部屋で岩を押して穴に落とすと北へ渡れる（看板で岩を元にもどせる）。左右の行き止まりの宝箱に「山神の鉞」「緋色の組紐」。はんざき大主は雷に弱い（スズの鳴神）。勝つと火種石
8. **奥ノ祠**：洞の奥の石段から。左右の影灯籠を祓うと結界が消える（湧き水で全回復・灯籠で記録）。宝箱に「宵明けの杖」「澄み鈴」「白絹の衣」
9. **宵喰らい**：灯（宵祓い）が弱点。HP が半分を切ると真の姿になり 2 回行動。守り鈴と灯の輪で立て直しながら、大木倒し・鳴神・宵祓いで攻める
10. **エンディング**：灯祭り → スタッフロール → クリアの記録
